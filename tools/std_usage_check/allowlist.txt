# path|headers|reason - the only places that may use the C++/C standard library (Phase 16 Day 220; gate: tools/std_usage_check/check.cmake).
# A covered file may spell `std::` and call C library names; it may include only the standard headers listed for it (`-` = none).
# An entry that covers no use, or lists a header no covered file includes, is stale and fails the gate. Every entry has a reason.
# The rule: CLAUDE.md ("The standard library is used only through the wrapper modules"), PLAN.md assumption #23, docs/guide/foundation-cstr.md.

# --- the wrapper modules ---------------------------------------------------------------------------------------------------------
engine/foundation/lang/|<utility>,<type_traits>,<limits>,<new>,<initializer_list>,<compare>,<cstddef>,<cmath>|Language support wrapper module (traits, Move/Forward, Limits, Ordering, new helpers, scalar math): the one place that spells these standard facilities.
engine/foundation/sync/|<atomic>,<mutex>,<condition_variable>,<thread>,<chrono>|Concurrency wrapper module (Atomic, Mutex, ConditionVariable, Thread): the one place that spells the standard concurrency types.
engine/foundation/cstr/|<cstring>,<cwchar>,<cstdio>,<cstdarg>,<cstdlib>,<charconv>|C string, memory, formatting and number wrapper module: the one place that calls the C library for them.
engine/foundation/os/console.h|<cstdio>,<cstdlib>|Console output, abort, _Exit and environment wrappers over the C library.
engine/foundation/os/last_error.h|<cerrno>|The errno wrapper (errno is a macro, so only a header can name it; the E* constants arrive through it).
engine/foundation/os/signal.h|<csignal>|The signal-handler wrapper (the SIG* constants arrive through it).
engine/jobs/coroutine.h|<coroutine>|The coroutine wrapper: the compiler looks coroutine machinery up by the standard names.

# --- documented boundaries ---------------------------------------------------------------------------------------------------------
engine/foundation/types.h|<cstdint>,<cstddef>|Defines the fixed-width aliases (u8..u64, usize, ...) and the byte type from the standard ones; everything else spells the aliases.
engine/foundation/os/posix/os_posix.cpp|-|The POSIX implementation of os::Exit (Linux and macOS) calls the C library's exit.
engine/foundation/os/windows/os.cpp|-|The Windows implementation of os::Exit calls the C library's exit.
tools/shader_mint/reflect_json.cpp|<vector>,<cstring>,<cstdio>,<algorithm>|The nlohmann/json boundary (PLAN.md assumption #19): the library is built on std::string and std::vector; the file converts to engine types at its edge.
tests/shader_mint/reflect_json_test.cpp|<string>,<vector>|Tests the nlohmann/json boundary file above, which takes and returns standard strings and vectors.
tests/support/catch_engine_types.h|<string>|Catch2 returns std::string at its boundary; this header adapts the engine's types to it.
