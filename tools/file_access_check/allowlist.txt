# path|reason - files (or directories, with a trailing /) allowed to call the operating system's file API directly.
# An entry that no longer exempts anything fails the gate (remove it). Lines between SIGNAL-SAFE markers need no entry.
# The rule and its exceptions: CLAUDE.md ("All file and directory access goes through io::File, io::Path and io::Directory") and
# docs/superpowers/specs/2026-11-06-file-layer-design.md (section 2, exceptions E1-E5).
engine/foundation/io/linux/|E5: the Linux backend of the file layer itself (file_system.cpp, local_file.cpp, directory.cpp, error.cpp).
engine/foundation/os/linux/os.cpp|E1: the descriptor primitives os::Open and os::CreateFileForWriting, kept for the assert-path debugger check and for the crash report, which opens its file inside the fault handler.
engine/foundation/os/linux/debug/module_list.cpp|E1: reads the executable path with readlink while a crash report lists modules (it may run in the fault handler, where the file layer cannot allocate).
engine/foundation/os/linux/debug/crash_context.cpp|E2: InitCrashContext reads /proc and the executable path with the raw descriptor primitives because the assert-failure handler can call it lazily while the heap may be inconsistent; the file layer allocates.
engine/foundation/os/linux/debug/fault_injection.cpp|E3: memfd_create makes anonymous memory for the fault-injection helper; it is not a path.
engine/foundation/os/linux/wayland/wayland_window.cpp|E3: memfd_create makes the shared-memory buffer shared with the compositor; it is not a path.
tests/io/|E4: the tests of the file layer plant files, links, permissions and temporary trees with the operating system directly, so they do not depend on the code under test.
tests/debug/|E4: the Phase 6 crash, core-dump and death tests drive the operating system on purpose (planting links, permissions and dump directories, reading what a crash left behind).
tests/jobs/async_io_test.cpp|E4: builds FIFOs and non-blocking descriptors to test that the I/O thread survives a blocking open; scratch files for the read tests.
tests/docgen/reference_test.cpp|E4: builds link loops, an unreadable directory and a read-only output directory, shapes the file layer's own helpers cannot create.
tests/docgen/samples_test.cpp|E4: a symbolic link to a program and the working directory, to test how the sample runner finds its compiler.
tests/rhi/vulkan_pipeline_test.cpp|E4: truncates and re-permissions cache files to test that the pipeline cache survives damage.
