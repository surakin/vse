## Post-implementation code review

`/code-review high`: 9 findings. Fixed (each with a regression test that fails without the fix, checked by reverting): `SendTo`/`ReceiveFrom` on a stream socket (the Linux truncation flag threw stream bytes away and `storage` was read uninitialised) now `Invalid`, storage zeroed; `FinishConnect` returned `WouldBlock` for ever on a socket that never connected or whose failure was already reported (now a `connecting_` state: `Invalid` unless a connect is under way, outcome reported once); `Receive` on a UDP socket cut a datagram silently (now `MessageTooLarge`, as `ReceiveFrom`); `Accept` now skips the transient per-connection errors of accept(2) (`EPROTO`, `ENETDOWN`, `ENOPROTOOPT`, `EHOSTDOWN`, `EHOSTUNREACH`, `EOPNOTSUPP`, `ENETUNREACH`); `EINTR` no longer maps to `WouldBlock` in the table; `SetReceiveBuffer`/`SetSendBuffer` return the `getsockopt` error instead of `granted == 0`; `OpenTcp`/`OpenUdp` share one private `Open`; the gate also names `getifaddrs`, `freeifaddrs`, `inet_aton`, `sendfile`, `sockatmark`; the tests no longer assume `ip_nonlocal_bind` is off, and the mapped-endpoint, unknown-scope-name, stream-datagram, `FinishConnect` and short-buffer cases were added. Declined: `::htons`/`::ntohs` with the `::` prefix (glibc defines them as macros that expand to a function-like macro, which the prefix breaks; they stay in the backend directory, where the gate allows them, and the Windows backend has its own); a shared byte-swap wrapper (two uses, both in this file); `poll`/`select` in the gate (they are not socket-specific and would flag the window layer's descriptor polling); matching `header_re` against comment-stripped text (an `#include` after `*/` on the same line is not a case worth the complexity); the port reuse race in the refused-connection test (the freed ephemeral port is not handed out again within microseconds in practice; the test accepts the connect error either way).
