# Phase 4 / Day 78 — Mesh Vertex Colors & Primitive Topology

**Phase:** [Phase 4 — Renderer Core](../phase-04-renderer-core.md)
**Depends on:** Day 77.

Two mesh-side capabilities the G-buffer pass and Phase 7's 3D text need: per-vertex colors, and triangle strips (with primitive restart) end to end.

## Tasks

- [ ] Per-vertex colors in meshes (needed by Phase 7's colored 3D text, and generally useful for tinted/baked geometry): `MeshData` gains an optional RGBA8 color array (absent means none; `StandardVertex` and every existing mesh and test stay unchanged); `GpuMesh` uploads it as a second vertex stream at a fixed location after the four standard attributes, and `ColorVertexLayout()` describes it (the pipeline cache already keys on the vertex layout). Colors are stored as authored sRGB bytes; the convention is written in the spec and header. The procedural builders get a way to set colors (a per-vertex callback or a constant). Tests: layout/offset/stride checks, upload round trip, validation of a color array whose length differs from the vertex count (named error), and a mesh without colors is byte-identical to before. The geometry shader side is Day 79.
- [ ] Triangle strips (and the other topologies) end to end. Today `rhi::PrimitiveTopology::TriangleStrip` exists in `GraphicsPipelineDesc` and maps to Vulkan, but nothing renders with it: no test draws a strip, the RHI has no primitive restart (so one indexed draw cannot hold several strips), and the renderer has no notion of topology. Add: (a) `GraphicsPipelineDesc::primitive_restart` (Vulkan `primitiveRestartEnable`; the restart index is the all-ones value of the index type; validated: only for indexed draws, and only strip topologies unless the device reports list-restart support), documented in the RHI header, with null-device validation; (b) an RHI GPU test with validation and sync validation that draws a quad as a 4-vertex strip, as an indexed strip, and two strips in one indexed draw split by a restart index, reading pixels back (a strip with the wrong winding alternation or a missing restart shows up as a wrong or missing triangle); (c) `MeshData`/`GpuMesh` carry a `PrimitiveTopology` (default `TriangleList`; line and point topologies allowed), the material template's pipeline state takes it from the mesh, and the pipeline cache key includes it, so a strip mesh and a list mesh with the same material get separate pipelines; (d) CPU helpers `StripToList` and `ListToStrip` (degenerate-triangle joins or restart indices, chosen by a flag) with tests that the triangle sets match, and a strip builder for the procedural meshes where it saves vertices (grid, cylinder side); (e) the culling and draw-sort paths handle strips (bounds come from vertices, not triangle counts), pinned by a test.
- [ ] **Documentation (CLAUDE.md "Public API is documented before a day is done"):** The vertex-color stream, `ColorVertexLayout`, `primitive_restart`, the mesh topology, the strip helpers and their conventions are documented in headers and the guide (RHI and renderer pages). `docgen lint` stays at zero findings, `cmake --build build --target docs` output is committed, `ctest -L docs` passes.
