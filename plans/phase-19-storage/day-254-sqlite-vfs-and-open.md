## Notes

- **Cross-process exclusion is not built.** The file layer has no file locks, and a lock file made with `kOpenCreateNew` would stay behind after a crash and refuse every later open. The in-process lock table and WAL index follow SQLite's real rules; a second process is not excluded. Listed in `KNOWN-ISSUES.md` with the options (a lock operation on `io::File`, `flock`/`LockFileEx` behind the file layer's backend interface).
- Added to `os/`: `WallClockUnixMillis` and `FillRandomBytes` (Linux `clock_gettime(CLOCK_REALTIME)` and `getrandom`; Windows `GetSystemTimePreciseAsFileTime` and `BCryptGenRandom`, with `bcrypt` linked to `foundation_base`; written on Linux, not built on Windows). macOS has no `os/macos/os.cpp` yet: the Mac line must add both.
- Fault injection (`SetFileFaults`, `sqlite_os.h`) fails the Nth write, sync or truncation; with `crash` set every file operation after it fails too, so nothing more reaches the disk. The sweep runs the three journal modes (`Delete`, `Truncate`, WAL) against each operation kind, with and without crash, for every N, plus a committed-before-crash check; 21,979 assertions.
- The `Path`-style bullet of the plan (a path style that is not the host's) does not apply: `OpenOptions::location` is text in the host's style.
- The conformance suite on a file: 32 of 32 cases pass (`SqliteFileFixture`); on memory 30 of 32 (2 skip). `Database::Supports` now reports what the backend can do for some database, a connection's `Supports` what its own database can (`ConcurrentReaders` only in the write-ahead log).
- tsan note for Day 255: the WAL index is plain memory read by several connections under SQLite's own protocol; the single-threaded tests here do not exercise it. The concurrency tests of Day 255 run it under tsan; a report there would be about the index, not the locks.
- Runs (Linux, Clang): plain `ran 2331 of 6104 tests (phases: all; flavors: plain; display: included; crash tests: excluded)`; asan `ran 1797 of 6104`; tsan `ran 1479 of 6104` (known failures only: the two X11 window tests, and the Day 235 tsan scene test). Clang non-unity and GCC: `database_tests` 133 of 133. `ctest -L docs` 7 of 7; database documented 143 of 143.
