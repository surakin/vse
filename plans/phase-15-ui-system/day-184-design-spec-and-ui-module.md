## Notes

- Spec: `docs/superpowers/specs/2026-11-10-ui-design.md` (linked from `docs/README.md`), with the spike numbers in its section 12. Spike A (2,000 rounded rects with borders): SDF quad 8,000 vertices / 11 us against tessellated 148,000 vertices / 1,044 us, so one SDF quad. Spike B (2,000 widgets, 6,000 glyph quads): 32,000 vertices, 61 us; the first try with a separate texture for rectangles and glyphs needed 4,000 commands, so the draw **mode is per vertex** (40-byte vertex with a `flags` word) and a frame is about 10 commands. Spike C: forward and backward cluster boundaries agree for a combining mark, a flag, a ZWJ family, a Hangul syllable and CRLF; no word movement exists, so the text field implements it in `ui`.
- Decisions changed from the planning notes: `ui::Key` is an alias of `os::Key` (no second enum; Days 184 and 192 amended); the draw mode is per vertex (Day 189 follows). Unchanged: SDF quad, logical units times scale, `UniquePtr` children with hashed ids, frame order, UI main-thread only, `ImageId` for images, the OS clipboard and drag and drop in the phase.
- Module: `engine/ui` (library `ui`, `_asan`, `_tsan`; `version.h` / `version.cpp` are placeholders until Day 189), `platform_input` INTERFACE target in `engine/platform/CMakeLists.txt` (include root only, no display library), `tests/ui` (`version_test.cpp`, phase 15, `flavors 15` lines), `CURRENT_PHASE` 15, `module_deps_check` rows (layer 11 beside the RHI), `ARCHITECTURE.md` row and graph lines, `docs/reference/modules.txt`, `docs/guide/ui.md` stub listed in the guide README. The doc lint baseline gained the `ui` module line (and refreshed the text and renderer counts).
