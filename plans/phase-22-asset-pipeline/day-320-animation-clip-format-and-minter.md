# Phase 22 / Day 320 — The Animation Clip Format, Its Source Form & the Clip Minter

**Phase:** [Phase 22 — Asset Pipeline & Resource System](../phase-22-asset-pipeline.md)
**Depends on:** Days 314-319 (blob container, skeleton, mesh).

A clip is sampled by time into a local pose. The format is chosen so that sampling reads the blob in place: no decompression into a scratch table when a clip loads (the phase's load rule), and a sample touches only the keys around the time asked.

## Tasks

- [ ] **The type:** `asset::types::kAnimation` (`ANIM`, version 1) is added to `resource_type.h` and the built-in registry, documented and tested like `kSkeleton` (Day 318).
- [ ] **Clip blob v1 (type `ANIM`):** header section (duration in seconds as `f32`, sample rate hint, flags: looping, additive, root-motion; the skeleton id as the standard dependency with role `skeleton`, and the 128-bit skeleton hash of Day 318), a track table (one entry per animated joint: joint index, which channels (translation, rotation, scale), key counts and section offsets), key time sections (`u16` quantized times in units of duration/65535 for tracks with irregular keys, or a constant-rate flag with no times at all), key value sections (rotations as three-component smallest-three `SNorm16` quaternions (6 bytes plus 2 bits of dropped-component index packed into the first word), translations and scales as `Float16x3` or full `f32x3` when the track range needs it, per-track min and extent so 16-bit values decode as `min + value * extent`), constant channels folded into the track table (no keys), event table (time, name hash, optional payload `u32`), per-clip bounds (the box over every sampled pose of the skeleton, for culling skinned meshes), and counts bounded by limits (joints 256, keys per track 65,535, events 1,024).
- [ ] **Error bound as part of the contract:** the minter measures the maximum rotation error (degrees) and translation error (relative to track extent) of the quantized clip against the source keys at every source key and at 8 mid-points per segment, writes the measured bounds into the blob header, and fails the mint when a bound exceeds the limit set by settings `assets.anim_rotation_error_degrees` (default 0.05) and `assets.anim_translation_error` (default 1e-4); the values are declared with `settings::Registry`.
- [ ] **Source form `.anim.src`:** text: `id <hex>`, `skeleton <hex id>`, `duration SECONDS`, `flags ...`, then per track `track JOINTNAME` followed by `t TIME x y z`, `r TIME x y z w`, `s TIME x y z` key lines (times strictly increasing, within duration), `event TIME NAME [payload]`; the parser reports line numbers; joint names resolve against the skeleton source named on the command line so the minter writes joint indices, and a name the skeleton lacks is the error that names the clip line; no glTF, FBX or BVH reader.
- [ ] **`ClipMinter`:** key reduction (drop keys that interpolate within the error bound, a deterministic greedy algorithm with fixed tie-break), constant-track detection, quaternion sign continuity and the hemisphere rule so interpolation takes the short way, quantization with the per-track ranges, bounds computation by sampling the skeleton through the `animation` evaluator on Day 321 (a clip minted before Day 321 lands carries bounds from the bind pose and is re-minted then; recorded here), deterministic output.
- [ ] **Loader `LoadClipBlob(bytes) -> ClipView`:** bounds-checked once, spans into the buffer, `Track(i)`, `Events()`; the clip binds to a skeleton only through `ClipView::Bind(SkeletonView)` which checks the skeleton hash and the joint count and returns `Invalid` with the message otherwise (Day 321 uses it); the dependency section holds the skeleton so the manager (Day 328) loads and type-checks it first.
- [ ] **Tests:** a table of source files (valid and each error with its line number); a 3-joint clip with known rotations round trips within the declared bounds (checked at 1,000 random times against a double-precision reference sampler written in the test); constant tracks produce no key sections; a looping clip's last pose equals its first within the bound; a clip bound to the wrong skeleton is refused; keys out of order, times past the duration, NaN values and a joint missing from the skeleton refused with line numbers; hostile blobs (track counts that overflow, offsets past the end, a dropped-component index above 3) refused; v0 golden blob refused and remint rewrites it byte-identical; minting twice is byte-identical.
- [ ] **Size check recorded:** a 60 s, 40-joint clip sampled at 30 Hz in the source minted and its blob size per second recorded in this file (the figure Day 337 compares against), with the error bounds the minter measured.
- [ ] **Runs (CLAUDE.md "Tests run by phase"):** `scripts/test-phase.sh --affected` plain; then the asan and tsan flavors when the day touched concurrency, lifetime or memory code; quote each run's final `ran X of Y tests (phases ...)` line in this file and never say "all tests pass" for a reduced run. `ctest -L docs` when a public header or a guide changed.
