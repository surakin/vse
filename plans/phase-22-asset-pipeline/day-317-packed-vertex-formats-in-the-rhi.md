# Phase 22 / Day 317 — Packed Vertex Formats in the RHI

**Phase:** [Phase 22 — Asset Pipeline & Resource System](../phase-22-asset-pipeline.md)
**Depends on:** Days 313-316; Phase 4 (`rhi::VertexFormat`, the backends), Phase 13 (DX12), Phase 21 (Metal).

Added on 2026-11-13 (the user asked to consider skeletons and animation before the mesh format). The RHI has only `Float1-4`, `UInt1-4` and `UNorm8x4`, so a mesh blob could not hold the compact attributes a GPU-ready format needs (16-bit texture coordinates, 8-bit normals and tangent frames, 8-bit joint indices, 8-bit skin weights) without a load-time conversion, which the phase forbids. This day adds the formats; Day 319 (mesh) and Day 322 (skinning) use them.

- [x] **The new formats** (one enumerator each, appended before `Count`, sizes in `VertexFormatSize`): `Float16x2`, `Float16x4`, `UNorm16x2`, `UNorm16x4`, `SNorm16x2`, `SNorm16x4`, `SNorm8x4`, `UInt8x4`, `UInt16x4`. `UNorm8x4` stays. Each is a vertex-buffer format the three APIs must support without a capability bit (Vulkan core lists `R8G8B8A8_SNORM`, `R8G8B8A8_UINT`, `R16G16_{UNORM,SNORM,SFLOAT}`, `R16G16B16A16_{UNORM,SNORM,UINT,SFLOAT}` as mandatory vertex formats; D3D12 and Metal likewise): if the Day 317 inventory finds one that is not, drop it from the list and say so here.
- [x] **Backend mappings:** a table entry per backend and format, with the Vulkan table checked by a test that asks the physical device for `VK_FORMAT_FEATURE_VERTEX_BUFFER_BIT` on every format the enum lists (so a wrong mapping or a missing feature fails at once), the DX12 table written to the same shape (`engine/rhi/dx12/`, Windows) and the Metal table (`engine/rhi/metal/`, Mac); the null backend accepts them. Alignment rules (a 6-byte `SNorm16x2` pair next to a 4-byte attribute) are checked by `Validate`, with a message naming the attribute.
- [x] **Shader reflection fit:** a `float4` (or `float2`) shader input accepts the float, half, UNorm and SNorm formats of the same width, a `uint4` input accepts `UInt8x4`, `UInt16x4` and `UInt4`; any other pairing is the existing pipeline-build mismatch error, with a test for each accepted and one refused pair per format.
- [x] **GPU readback test (Vulkan on Linux):** a vertex shader that passes each attribute through to a storage buffer; the test draws one point per format with known bytes and reads back the decoded values (UNorm16 0xFFFF reads 1.0, SNorm8 0x81 reads -1.0, half 0x3C00 reads 1.0, UInt8 0xFF reads 255); the same test runs on DX12 and Metal on their machines (`[.]`-free, skipped without the backend). The shader is a new Slang source with committed outputs like the others.

## Outcome
