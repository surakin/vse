## Outcome

Done (2026-11-15, Linux). `ENGINE_API`/`ENGINE_API_CALL` in `build_defs.h` (used by `engine_shared.cpp`, built with `ENGINE_BUILDING_LIBRARY`); `abi/engine.exports` (version `1.0`, one symbol) is the one export list: the linker's version script is generated from it at configure time (`engine_shared.map` in the build tree; the node is `ENGINE_<major>`) and the library's `VERSION` and `SOVERSION` come from its version line; `engine/engine_c/engine_abi_version.h` carries the same numbers. The gate `tools/abi_check` (`abi_check`, `abi_check_library` in the three flavors, 12 planted-violation cases each also run for its exit code): the list, the version header, the built library's `nm -D` symbols (exactly the list), the last commit's list through git (an added symbol needs a minor bump, a removed one a major bump, never down), and, once `engine_c.h` exists, valid C11 and no C++ token. The new guide page `docs/guide/engine-library.md` says how to add an export.

Runs: `scripts/test-phase.sh --affected` plain (it ran everything: `build_defs.h` is a foundation header): `ran 3328 of 8847 tests (phases: all; flavors: plain; display: included; crash tests: excluded)`, the two failures are the locked-session X11 tests; in the shared tree (`-DENGINE_BUILD_SHARED=ON`) `abi_check*` 29 of 29 and the link probes in all three flavors pass; `ctest -L docs` 7 of 7; GCC compiles `engine_shared.cpp`. No code that runs changed beyond one exported function: no sanitizer flavors of the suites.
