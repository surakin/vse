## Outcome

Done (2026-11-15, Linux). `docs/superpowers/specs/2026-11-16-engine-library-design.md`: eleven decisions (the planner's defaults, confirmed by the user the same day), the three spike records, the singleton survey and the consequences for the days. The spikes (a PIC build of the foundation, the job system and the crash facade with its C libraries linked into one `.so`, small C hosts, asan and tsan flavors) found: the engine's libraries are not PIC yet; `-fvisibility=hidden` leaves about 500 symbols exported (so the version script is the export list), and exporting standard-library symbols pins the library in memory; two libraries that each carry the foundation have two logs and two allocators (one engine library, plugins link the C API only); a sanitized engine loads only into a host built with the same sanitizer; the library unloads only when no engine code ran on a host thread that has a `thread_local` with a destructor (the job system's frame-pool cache and the crash facade's alternate stack), which Day 345 converts. Added: the option `ENGINE_BUILD_SHARED` (default OFF; it only says so when ON), the test `engine_shared_option` (the option exists, is boolean, is declared OFF in every platform branch; a planted ON fails), `tests/engine_library/`, the phase label and flavor lines for phase 23, `BUILD.md` and the guide text, PLAN.md assumption #27, `CURRENT_PHASE` 23.

Runs: `scripts/test-phase.sh --affected` plain: `ran 3299 of 8814 tests (phases: all; flavors: plain; display: included; crash tests: excluded)`; the two failures are the X11 window tests of a locked session (`KNOWN-ISSUES.md`); `ctest -L docs` 7 of 7.
