# Phase 23 / Day 347 — The Loader, the ABI Snapshot & the C Host

**Phase:** [Phase 23 — The Engine as a Loadable Library](../phase-23-engine-as-library.md)
**Depends on:** Day 346.

`engine_loader.h`, a C host that loads the shared library with `dlopen`, and the ABI snapshot test.

## Tasks

- [x] `engine_loader.h` (header-only, C, no engine dependency): `engine_load(path, wanted_major, wanted_minor, engine_loader* out)` opens the library (`dlopen`/`LoadLibraryW`/`dlopen` with the platform's flags decided on Day 342), resolves `engine_get_api`, checks the version and the table size, and fills a message for every refusal (missing file, missing symbol, incompatible major, too-old minor); `engine_unload`.
- [x] `tests/engine_library/host_c.c` grows: it loads the library at run time (path from a test argument), runs a headless frame (the frame loop of Day 349 is a stub returning success until then), shuts down and unloads; run in plain, asan and tsan.
- [x] Refusal tests: a library with another major version (a test build with a bumped `ENGINE_ABI_VERSION`), a file that is not a library, a library without the entry point: each refused with a message, no crash.
- [x] The **ABI snapshot test**: `abi/engine_api.snapshot` records the table's function names, their order and every struct's size and field offsets (generated by a small C program compiled against `engine_c.h`); the test fails on any difference unless the minor version changed and only appends happened.
- [x] Language-binding stability note in the guide (Phase 27 binds through this table).
- [x] **Runs (CLAUDE.md "Tests run by phase"):** `scripts/test-phase.sh --affected` plain; then the asan and tsan flavors when the day touched concurrency, lifetime or memory code (this phase does, nearly every day); quote each run's final `ran X of Y tests (phases ...)` line in this file and never say "all tests pass" for a reduced run. `ctest -L docs` when a public header or a guide changed. Build clean (warnings are errors) with both compilers, unity on and off, **and with `-DENGINE_BUILD_SHARED=ON`** from Day 343 on.
- [x] **Three machines (CLAUDE.md):** this day is built and tested on the Linux machine; shared code (CMake, the gates, the C header, the loader) is checked on the other two no later than Day 357; until then the day is "open until the other machines run it" in `KNOWN-ISSUES.md`.
- [x] **Documentation (CLAUDE.md "Public API is documented before a day is done"):** headers carry `///` comments with the contract labels (`engine_c.h` has its own comment convention, set on Day 346, checked by `docgen` or its own gate); `docgen lint` at zero; `cmake --build build --target docs` output committed; the guide `docs/guide/engine-library.md` is updated.
- [x] **Module rules (CLAUDE.md):** a new module, target or edge updates `ARCHITECTURE.md`, `tools/module_deps_check/modules.txt` and `BUILD.md` (a new prerequisite) in the same commit; every new test file has its line in `tests/phases.txt` (phase 23).
- [x] **Day review (CLAUDE.md, required):** `/code-review high` over the day's diff after the scoped tests; verify, fix (with a regression test that fails without the fix) or decline each finding with a reason; record the count and outcome under "Post-implementation code review" below and in `STATUS.md`.
- [x] `STATUS.md` and `KNOWN-ISSUES.md` updated in the same commit; commit and push.

**Done:** a C host loads the shared engine, checks its version, runs a headless frame, shuts down and unloads; the snapshot and the refusal tests pass.

## Outcome

Done (2026-11-15, Linux). `engine/engine_c/engine_loader.h` (header-only C; POSIX `dlopen`, the Windows variant is Day 354): `engine_load`/`engine_unload`, a message for every refusal. `tests/engine_library/host_dl.c` (not `host_c.c`: that one links the C API statically and has `engine_get_api` in its own image) loads the real library, creates an engine, runs jobs through the test extension (the frame loop is Day 349; no stub was added to the ABI), destroys, unloads and checks the library left the address space; plain, asan, tsan. Refusals tested: a missing file, a file that is not a library, an empty path, a library without the entry point, another major, a table that lies, and the real library asked for a newer minor and another major (stand-ins in `fake_engine.c`). ABI snapshot: `abi/engine_api.snapshot` (status values, struct sizes and field offsets, from `abi_snapshot_gen.c`), test `engine_abi_snapshot` (identical, or an append under a higher minor; the rules were exercised by hand against a changed field, a same-minor append and another major), target `engine_abi_snapshot_update`. Guide: "Loading the library" and "what a binding may rely on". Runs: plain `ran 3350 of 8884 tests (phases: all; flavors: plain; display: included; crash tests: excluded)`, asan `ran 2676 of 8884`, tsan `ran 2346 of 8884`; the shared tree's `engine_*` and `abi_check*` pass; docs 7 of 7; Clang unity, non-unity and GCC build clean. Failures not from this day: `BC1, BC4, BC5 and BC7 textures sample on the GPU...` (plain and asan, from the Windows PC's `e9a1af54`), and the four known tsan Vulkan SEGFAULTs.
