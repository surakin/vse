## Post-implementation code review (end of phase)

`/code-review high` over `24f76a0..HEAD` (Days 103-114 as committed): 9 findings. Fixed: a renderer over a null device without a host no longer assumes Vulkan or enumerates Vulkan adapters (settings derived from `create_info`); a swapchain request the surface refuses no longer marks the swapchain lost, restores the previous description and so allows a real rollback (previously the rollback path was unreachable on Vulkan); `FailedOwner` returns a copy of the name, not a pointer into a dead owner; the begin and end callbacks stay balanced when a failed change goes on to a recovery (the recovery starts after the end callback; test added); `GpuTexture` and `GpuMesh` no longer close a caller's open frame when they make GPU mips or prepare buffers (test added); the null device consumes the batch of an injected submit loss as Vulkan does; a settings change or forced reset with no device returns a reason instead of dereferencing null; the demo no longer uses `std::pair`; `STATUS.md` has its Day 114 line. Declined: the Vulkan swapchain keeping a minimized-format record (reverted instead: `ImageFormat()` keeps matching the live images and the tonemap pipeline follows the output format every frame anyway).
