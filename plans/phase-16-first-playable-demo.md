# Phase 16 — First Playable Demo

**Depends on:** Phases 0-9 at minimum (core engine, physics, audio,
scripting); Phase 15 (editor) helps but isn't strictly required if content
is still hand-authored via the asset pipeline.
**Goal:** a small real game built with the engine — the first genuine
dogfooding of every system, surfacing real bugs and API ergonomics
problems that no amount of isolated testing would find.
**Definition of done:** a playable (even if tiny/rough) game exists, built
using the engine's own tools/pipeline, running on at least Linux and
Windows.

## Key deliverables (to be expanded into day-by-day tasks when started)

- Game design scope kept deliberately small — this is a dogfooding
  exercise, not a product. Concrete scope (genre, mechanics) to be decided
  when this phase starts, informed by what the engine can actually do at
  that point.
- Fixes/refinements to every touched system, tracked as they're found
  rather than speculated now.

## Notes / open questions

- Full day-by-day breakdown deferred until Phase 9 (and ideally 15) is
  complete.
- This phase is expected to feed back into earlier phases' plans (bug
  fixes, API changes) — that's the point of it existing.
