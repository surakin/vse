# Phase 7 / Day 103 — Design Spec, Reset Spike & Phase Setup

**Phase:** [Phase 7 — RHI Reset](../phase-07-rhi-reset.md)
**Depends on:** Phase 6 complete (Day 102).

Settle the architecture by measuring before building: can a Vulkan device be destroyed and re-created in one process, on the
same window, repeatedly, without leaks or validation errors, and what does it cost? Write the spec the other days follow.
