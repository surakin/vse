# Phase 25 / Day 378 — The Fixed-Step Driver and Integration

**Phase:** [Phase 25 — Physics](../phase-25-physics.md)
**Depends on:** Day 377.

Time stepping that is the same on every machine, and bodies that fall.

## Tasks

- [x] `PhysicsWorld::Update(real_dt)`: an accumulator advances in fixed steps (`physics.step_hz`, default 60, a setting through `settings::Registry`), at most `physics.max_substeps` (default 4) per call; a longer frame drops the remainder and counts it in the stats (no spiral of death).
- [x] `Step()`: apply forces and gravity to velocities, damping, (broad phase, narrow phase, solve are later days), integrate positions with semi-implicit Euler, orientation update by quaternion with normalisation using `Sqrt` only; kinematic bodies move by their target.
- [x] Interpolated write-back: the `Transform` of each dynamic body is the blend of the last two states by the accumulator fraction, so rendering at any frame rate shows smooth motion; `physics.interpolate` can turn it off; teleports skip interpolation.
- [x] Gravity: a world vector and a per-body scale; forces and torques accumulate and clear each step; `ApplyImpulse` acts at once.
- [x] A system `PhysicsStepSystem` in the ECS schedule with declared reads and writes (reads `RigidBody`, `Collider`, `Transform` of kinematic bodies; writes `Transform` of dynamic ones) **(built as `MakePhysicsStepSystem()`; the frame's time is the schedule's `Dt`, no extra resource)**, so the Phase 17 scheduler orders it against other systems.
- [x] Settings: `physics.step_hz`, `physics.max_substeps`, `physics.gravity` **(built as `physics.gravity_y`: settings have no vector type)**, `physics.interpolate` declared with env and flag names; `config_access_check` stays green.
- [x] Tests: a sphere in free fall matches the closed form for position within the semi-implicit Euler error bound and exactly matches a reference implementation of the same recurrence; the accumulator (a 100 ms frame runs the capped substeps, the remainder is dropped and counted); interpolation at fraction 0, 0.5, 1; a spinning body keeps a unit quaternion over 10^5 steps; the state hash of a 600-step run is stable across runs and thread counts (committed constant) **(thread counts do not apply: the step is single-threaded until Day 389)**.
- [x] **Runs (CLAUDE.md "Tests run by phase"):** `scripts/test-phase.sh --affected` plain; then the asan and tsan flavors (this phase is concurrency, lifetime and memory code on nearly every day); quote each run's final `ran X of Y tests (phases ...)` line in this file and never say "all tests pass" for a reduced run. `ctest -L docs` when a public header or a guide changed. Build clean (warnings are errors) with both compilers and unity on and off; `-DENGINE_BUILD_SHARED=ON` and `-DENGINE_LIBRARY_WITH_IMPORTER=OFF` still build.
- [x] **Three machines (CLAUDE.md):** built and tested on the machine the day is done on (Linux); shared code (CMake, flags, the gates, tests, headers) is checked on the Windows PC and the Mac no later than Days 398-399, and `KNOWN-ISSUES.md` lists what waits for those runs.

## Outcome

Built: `PhysicsWorld::Update/Step/Alpha/Interpolated/StateHash/SetStepConfig` (`step.cpp`), `StepConfig`, `StepStats`, `previous_position/orientation` on `Body`, `physics_settings.h/.cpp` (`physics.step_hz`, `physics.max_substeps`, `physics.gravity_y`, `physics.interpolate`, env `ENGINE_PHYSICS_*`, flags `--physics-*`), `system.h/.cpp` (`WriteBackTransforms`, `MakePhysicsStepSystem`). The step is semi-implicit Euler on `+ - * /` and `Sqrt` only: gravity and forces to velocity, damping `v / (1 + c dt)`, the centre of mass moves, the orientation turns by `q + dt/2 (w, 0) q` normalized; kinematic bodies move by velocity about their origin; static bodies are skipped. The accumulator caps at `max_substeps` and drops and counts the rest. A process that flushes denormals is reported (`ENGINE_ENSURE`, `denormal_mode_steps`).
Checks: free fall equals the same recurrence bit for bit over 120 steps and the discrete closed form within 2e-3; forces, gravity scale, damping and the three body types; a unit quaternion within 2e-6 after 100,000 steps and the centre of mass of an offset collider fixed within 2e-3 while spinning; the accumulator (36 steps from sixty 10 ms frames, a 100 ms stall runs 4 and drops 0.0333 s); config validation; interpolation at 0, 0.5, 1, after a teleport, with a spin and with interpolation off; the 600-step scene's **state hash `238b01a717a849dd`**, equal under clang and GCC, unity and not, Debug and Release (`-O2`); the settings; the schedule system and write-back with no access violations.
**Deviations:** (1) the hash is stable across runs and builds, not "thread counts": the step is single-threaded until Day 389. (2) `physics.gravity` is `physics.gravity_y` (the settings have no vector type; sideways gravity is `StepConfig::gravity` in code). (3) No extra time resource: the system reads the schedule's `Dt`. (4) No gyroscopic term (documented). (5) The broad phase does not use the world's `SpatialWorld` "physics" set: `BroadPhase` owns its own set (Day 377); revisit when spatial queries must see physics colliders (Day 391).
**Runs:** plain `ran 3446 of 9128 tests (phases: all; flavors: plain; display: included; crash tests: excluded)`, asan `ran 2756 of 9128 ...`, tsan `ran 2414 of 9128 ...`, no failure; GCC, non-unity and Release `physics_tests` 64 of 64; `ctest -L docs` 8 of 8, docgen lint at zero for `physics`. Not run: the shared-library and importer-off builds, the Windows and macOS machines.

## Post-implementation code review

`/code-review high` over the diff, read with the eight angles: 1 finding, fixed with a regression test. A finite but absurd angular velocity (1e30) overflowed the quaternion's squared length in `Turn`, and `Quaternion::Normalized` aborts on a non-positive length: the step now keeps the orientation when the length is not usable (test `an absurd but finite spin does not abort the step`; it aborted before the fix, as the first run of the test showed). A missing include (`settings/setting.h`) hidden by the unity build was found by the GCC build and fixed. Declined: none.
