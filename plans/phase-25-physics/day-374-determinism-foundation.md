# Phase 25 / Day 374 — Determinism Foundation: Flags, Operation Rules and the State Hash

**Phase:** [Phase 25 — Physics](../phase-25-physics.md)
**Depends on:** Day 373.

Make the build produce the same floating-point results everywhere before a line of physics exists.

## Outcome

The build now forbids the two things that change float bits: `ENGINE_FP_COMPILE_OPTIONS` (`-ffp-contract=off -fno-fast-math` on GCC/Clang, `/fp:precise` on cl, plus `/clang:-ffp-contract=off` on clang-cl) is applied to every target of ours on the three platforms' build paths, and `cmake/EngineFpCheck.cmake` stops the configure step on a fast-math or contraction flag in `CMAKE_C/CXX_FLAGS`, their per-configuration variants or the linker flags (tested on planted flags by `physics_fp_flags_check`). The new module `engine/physics` (layer 13; `ARCHITECTURE.md`, `modules.txt`, `module_map.txt`, `docs/reference/modules.txt`, `phases.txt`, the root CMake on all three platform paths) holds `state_hash.h` (`StateHasher`: FNV-1a 64, little-endian words, -0.0 hashed as +0.0, NaN/infinity make it invalid) and `determinism.h/.cpp` (`ProbeHash`, `ContractionObserved`, `DenormalsPreserved`, `ModeReport`). The probe hash `50e1be9251ea408f` is the same under GCC 16 and Clang 23, `-O0` and `-O3`, unity and non-unity, plain/asan/tsan, and with `-march=native -ffp-contract=off`; with contraction on it is `60498f6f6e05389d` under both compilers (the first probe, in which two expressions shared one product, did not change under GCC: it was rewritten so each product has one use). A control probe compiled with `-ffp-contract=fast -mfma` shows the test would see a fused multiply-add. Denormals: kept, never flushed; no `os/` wrapper was needed (the step will check `DenormalsPreserved()` on Day 378). `docs/guide/physics.md` states the rules.
**Runs:** `scripts/test-phase.sh --affected`: plain `ran 3391 of 8963 tests (phases: all; flavors: plain; display: included; crash tests: excluded)`, asan `ran 2701 of 8963 tests (phases: all; flavors: asan; display: included; crash tests: excluded)`, tsan `ran 2359 of 8963 tests (phases: all; flavors: tsan; display: included; crash tests: excluded)`; all passed (every phase ran because `cmake/` changed). `ctest -L docs` 8 of 8; `docgen lint` physics 15/15. `physics_tests` also passed in the GCC, Release (clang -O3) and non-unity trees. **Not run:** `-DENGINE_BUILD_SHARED=ON` and `-DENGINE_LIBRARY_WITH_IMPORTER=OFF` (no engine library code changed; the flags apply to them like any target), the Windows and macOS machines.
