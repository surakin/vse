# Phase 6 / Day 94 — Vendoring libbacktrace & the Stack-Trace Facade

**Phase:** [Phase 6 — Debugging Facilities](../phase-06-debugging-facilities.md)
**Depends on:** Days 91-93.

Stack capture and symbolization come from libbacktrace (`PLAN.md` assumption #20, confirmed on Day 91). This day vendors
it, builds it under our CMake, and puts our small facade in front of it so the rest of the engine never sees it.

## Tasks

- [ ] Vendor libbacktrace as source under `third_party/libbacktrace/` at the commit Day 91 pinned (`0b9b49cf4a2c9229fc052d6716e1528b2f23e91a`, no releases exist; draft `VENDORED.md` is in the spec, section 7): only the files needed (`backtrace.c`, `dwarf.c`, `elf.c`, `fileline.c`, `macho.c`, `mmap.c`, `mmapio.c`, `pecoff.c`, `posix.c`, `print.c`, `read.c`, `simple.c`, `sort.c`, `state.c`, `alloc.c`, `atomic.c`, `unknown.c`, `internal.h`, `backtrace.h`, `backtrace-supported.h`), its `LICENSE`, and a `VENDORED.md` (upstream URL, pin, license, what was pruned, what was added). No submodule, no `FetchContent`.
- [ ] Write `third_party/libbacktrace/CMakeLists.txt` replacing its autotools: the `config.h` it needs from `check_symbol_exists`/`check_include_file` (`HAVE_DL_ITERATE_PHDR`, `HAVE_SYS_MMAN_H`, `HAVE_ATOMIC_FUNCTIONS`/`HAVE_SYNC_FUNCTIONS`, `HAVE_CLOCK_GETTIME`, `HAVE_GETIPINFO`, `HAVE_LINK_H` and the others in the Spike C list; `BACKTRACE_USES_MALLOC` stays 0; zlib, zstd and lzma are left off, which only loses compressed DWARF sections: say so in `VENDORED.md`), the object formats enabled per platform (ELF and Mach-O and PE sources compiled everywhere or only where the platform needs them, as Spike C decided), one static library `backtrace` built once and linked into the plain, ASan and TSan flavors (Day 91, Spike C: an instrumented program calling the plain library worked in all three), the library's own warning flags, and no `-Werror`. The vendored sources are never edited; if one must be, the change is listed in `VENDORED.md` as an `[engine patch]` like Catch2's.
- [ ] Add `engine/foundation/debug/stack_trace.h`: `StackTrace` (fixed capacity of 64 `u64` addresses, a count, a `truncated` flag), `CaptureStackTrace(StackTrace&, skip_frames)`, `ResolveStackTrace(const StackTrace&, FrameInfo* out, usize count)` giving per frame the module, function name, file and line (inlined frames included; a frame with no function name from `backtrace_full`, such as libc, falls back to `backtrace_syminfo`; the unwinder's bogus last frame with pc `0xffffffffffffffff` is dropped), and `FormatStackTrace(trace, char* out, usize capacity)` with one fixed line layout (`#N  0xADDR  function  file:line`, falling back to `module+offset` or the raw address). Neutral: no libbacktrace type in the header.
- [ ] Add the one implementation file `engine/foundation/debug/stack_trace_backtrace.cpp`, the only file that includes `backtrace.h`: one `backtrace_state` created at first use or at `InitDebugFacilities()` (the first call walks the loaded objects with `dl_iterate_phdr` and is not async-signal-safe, so startup makes it; the crash path only reuses it), an error callback that records the message instead of printing, `backtrace_simple` for capture, `backtrace_pcinfo`/`backtrace_syminfo` for resolution. No frame-pointer requirement: the compiler's unwinder is used, so no change to `ENGINE_PRODUCTION_COMPILE_OPTIONS` is needed (confirm against Spike C).
- [ ] The library gate: extend the Day 92 platform-neutral gate (`tools/platform_neutral_check`) so a file includes `backtrace.h` only if it is `stack_trace_backtrace.cpp`, with a planted-violation fixture.
- [ ] Demangling: the formatter demangles names with the C++ ABI's `__cxa_demangle` only in the non-signal path (it allocates), with a fixed-size output buffer and a fallback to the mangled name; the signal path prints mangled names.
- [ ] Wire the assert family: a failing `ENGINE_ASSERT` and the first failure of each `ENGINE_ENSURE` site print the formatted trace under the message (Day 93 left the hook).
- [ ] Tests (in `tests/debug`): a call chain of known depth resolves to the right function names and source lines in a `-g` build (a planted function at a known line of a test source); a trace from a `std::thread`; from a job-system coroutine resumed on a worker; a stripped copy of the test binary falls back to `module+offset`; a symbol in a `dlopen`ed library is found; a trace of 10000 frames is truncated and flagged; formatting never overruns (ASan, capacities 0, 1, 80, 4096); the capture-and-resolve path run inside a `SIGUSR1` handler (child process) completes and, with a counting allocator, allocates nothing after the startup call; the test also runs under ASan and TSan, and the behavior with fake stacks (`detect_stack_use_after_return`) is recorded.
- [ ] Build checks: the library compiles without warnings we own under GCC and clang in plain, unity and sanitizer builds; `-DENGINE_UNITY_BUILD=ON` does not batch the third-party target (`SKIP_UNITY_BUILD_INCLUSION` or its own directory setting, recorded in `VENDORED.md`).
- [ ] **Documentation:** `///` comments with `Thread-safety:` and `Fails:` labels; `docs/guide/foundation-debugging.md` created with "Capturing and reading a stack trace" (tagged compiled sample); the module `foundation/debug "Foundation: Debugging"` added to `docs/reference/modules.txt` with the strict rules; reference regenerated and committed; `docgen lint` at zero; `ctest -L docs` passes.
- [ ] Run the day's scoped tests (`--affected`; the day changes CMake, so it runs everything), then `--flavor asan` and `--flavor tsan`, and quote the `ran X of Y tests` lines.
- [ ] **End-of-day review (CLAUDE.md):** `/code-review high` on the day's diff (our CMake wrapper, the facade, the tests; the vendored sources are reviewed only for what was pruned or patched); record it here and in `STATUS.md`.
- [ ] Update `STATUS.md`; commit.

**Done:** libbacktrace builds from vendored source under our CMake in all flavors; `stack_trace.h` captures, resolves and formats a trace without any library type in sight; assert and ensure print traces with file and line; the tests pass in plain, ASan and TSan; the gate keeps `backtrace.h` out of every other file.
