bool RegisterMetalBackend();

Registers the Metal backend (`Backend::Metal`, name `metal`, Metal libraries) with the backend registry. macOS only.

Called by [`rhi::RegisterCompiledBackends`](rhi.md#rhi-registercompiledbackends); calling it again changes nothing. The backend is available when the system lists a Metal device of the Mac2 family that supports Metal 3. `Auto` picks it on macOS, where it is the only GPU backend (rank 30).
