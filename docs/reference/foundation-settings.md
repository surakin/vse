# Foundation: Settings

_Generated by docgen. Do not edit._

**Headers:** `engine/foundation/settings/desc.h`, `engine/foundation/settings/key.h`, `engine/foundation/settings/registry.h`, `engine/foundation/settings/setting.h`, `engine/foundation/settings/value.h`

The declaration of one setting, and the text form of its values.

Setting keys: validated dotted names such as `renderer.present_mode`.

A key has one to three segments separated by `.`; a segment is a lowercase letter followed by lowercase letters, digits and `_`, at most 31 bytes; the whole key is at most 95 bytes. In a text file the key `renderer.width` is the name `width` in the section `[renderer]`, and `a.b.c` is `c` in `[a.b]`; [`settings::Key::Section`](#settings-key-section-const) and [`settings::Key::Name`](#settings-key-name-const) give that split.

The registry of settings: what exists, with its type, default, range and metadata, and the current value of each.

A registry is filled at start-up ([`settings::Registry::Register`](#settings-registry-register-const-settingdesc-amp-registererror-star)), frozen ([`settings::Registry::Freeze`](#settings-registry-freeze)) and then only read; the current values change through [`settings::Registry::Publish`](#settings-registry-publish-settingid-const-value-amp) (the settings service does this) and are read by typed handles ([`settings::Setting`](#settings-setting)) at the cost of one relaxed atomic load.

Typed handles for reading a setting: `Setting<bool>`, `Setting<i64>`, `Setting<f32>`, `Setting<f64>` and `Setting<E>` for an enum type `E`, and [`settings::TextSetting`](#settings-textsetting) for text.

A handle is one pointer. `Get()` is one relaxed atomic load and a decode, so it is safe and cheap in a hot path from any thread; it sees a published value on the next call after `Registry::Publish` returns. A handle made for the wrong type aborts at creation.

A setting's value: a small tagged value that is cheap to copy and owns no heap memory.

The forms: `true`/`false` (also `yes`, `no`, `on`, `off`, `1`, `0`) for a bool; a decimal or `0x` hexadecimal integer; a decimal float with an optional exponent; an enum name; text, bare or double-quoted with the escapes `\"`, `\\`, `\n`, `\t` and `\xHH`.
