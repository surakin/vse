The result of a read from a [`bytes::ByteReader`](#bytes-bytereader).

[`bytes::ByteReader`](#bytes-bytereader): the canonical byte encoding, read back with every access bounds-checked. The matching writer is [`bytes::ByteWriter`](#bytes-bytewriter).

[`bytes::ByteWriter`](#bytes-bytewriter): the canonical byte encoding, written. Little-endian, fixed-width integers, floats as their bit patterns, no padding. The matching reader is [`bytes::ByteReader`](#bytes-bytereader) (`bytes/byte_reader.h`). Storage and networking share them.

## `ByteReader` {#bytes-bytereader}

`class bytes::ByteReader` — defined in `engine/foundation/bytes/byte_reader.h`

```cpp
class ByteReader { ... }
```

Reads values from a span of bytes, in the encoding [`bytes::ByteWriter`](#bytes-bytewriter) writes. Input is untrusted: a read that would pass the end returns [`bytes::ByteError::Truncated`](#bytes-byteerror-truncated), a length above the caller's limit returns `TooLong`, and a malformed value returns `Invalid`. A failed read does not move the reader and does not write its output. The reader never reads outside the span it was given.

| Field | Value |
|---|---|
| Thread-safety | not-thread-safe; synchronize externally if shared. |
| Ownership | borrows the span; the bytes must outlive the reader and every span it hands out. |

## `ByteWriter` {#bytes-bytewriter}

`class bytes::ByteWriter` — defined in `engine/foundation/bytes/byte_writer.h`

```cpp
class ByteWriter { ... }
```

Appends values to a growing buffer in the canonical encoding: every integer little-endian at its own width; `f32` and `f64` as the bit pattern of the value (a NaN payload, `-0` and denormals survive); `bool` as one byte (0 or 1); lengths as unsigned LEB128 varints in their shortest form.

| Field | Value |
|---|---|
| Thread-safety | not-thread-safe; synchronize externally if shared. |
| Ownership | owns the buffer; `Bytes()` views it until the next write or `Clear`. |
