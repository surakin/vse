# Animation runtime

_Generated by docgen. Do not edit._

**Headers:** `engine/animation/components.h`, `engine/animation/pose.h`, `engine/animation/sampler.h`

The animation components and the system that plays them. Phase 22 Day 321.

Poses and what is done with them: the local pose of every joint, the blends, the additive pose, the model-space walk and the skinning palette. Phase 22 Day 321. A pose is a fixed structure of 256 joints (the palette limit): every operation works in place on storage the caller owns and allocates nothing.

The clip sampler: a clip, a skeleton and a time give a local pose; plus the time advance, the events crossed and the root motion over a step. Phase 22 Day 321. Nothing is decoded into a table: keys are decoded where they are read.

Collects the events crossed while time moved from `from` by the advance `advance`, in time order: an event at time `e` is crossed when `from < e <= new time` (a loop adds `from < e <= duration`, any whole passes, and `0 <= e <= new time`). `include_start` also includes an event at exactly `from` (the first frame of a play).

| Field | Value |
|---|---|
| Parameter `out` | receives up to `out.Size()` events; the rest are dropped and `*overflow` is set. |
| Parameter `overflow` | may be null. |
| Returns | the number of events written. |
| Ownership | borrows its arguments for the call. |
