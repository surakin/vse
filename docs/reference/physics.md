## `BroadPhase` {#physics-broadphase}

`class physics::BroadPhase` — defined in `engine/physics/broad_phase.h`

```cpp
class BroadPhase { ... }
```

Finds the pairs of colliders that may touch.

Nothing new is built here: the colliders go into a `spatial::SpatialSet` (the static ones in its tree, the moving ones in its dynamic tree with fat boxes) and a `spatial::PairTracker` keeps the pairs, in sorted order. Each `Update` first brings the set in line with the physics world (adds, removes and moves what changed, rebuilds the static tree when it needs it), then updates the pairs.

## `ProbeHash()` {#physics-probehash}

`function physics::ProbeHash` — defined in `engine/physics/determinism.h`

```cpp
u64 ProbeHash();
```

Hashes the results of a fixed set of expressions that a changed rounding, contraction or flush mode would change.

The set holds sums and products that a fused multiply-add rounds differently, a chain of `Sqrt`, conversions between integers and floats, and denormal inputs and results. Every operation is one IEEE 754 defines exactly (`+ - * / Sqrt`, conversions), so the value is the same on every machine and every compiler whose flags follow the rules; the tests compare it with a committed constant and the Windows and macOS machines compare it with the same constant.

| Field | Value |
|---|---|
| Returns | the hash. |
| Thread-safety | thread-safe; pure. |

## `SyncBodies(ecs::World&,PhysicsWorld&)` {#physics-syncbodies-ecs-world-amp-physicsworld-amp}

`function physics::SyncBodies` — defined in `engine/physics/sync.h`

```cpp
SyncReport SyncBodies(ecs::World& ecs, PhysicsWorld& physics);
```

Makes the physics world follow the ECS world.

It destroys the bodies of entities that are gone or lost their `RigidBody` or `Collider`, updates a body whose components changed, and creates a body for every new entity.

Entities are visited in entity order (index, then generation), not in chunk order, so two worlds built the same way get the same body ids. A new body starts at the entity's `LocalTransform` and `Velocity` (optional); an entity with a `Parent` is not simulated (a body has no parent). The call changes the ECS world's structure (it adds and removes `BodyLink`), so it runs between iterations, at a sync point.

| Parameter `physics` | the physics world. |
| Returns | what was done. |
| Fails | an entity with invalid components is counted in `refused` and skipped. |
| Aborts | called while the ECS world is being iterated. |

## `PhysicsWorld` {#physics-physicsworld}

`class physics::PhysicsWorld` — defined in `engine/physics/world.h`

```cpp
class PhysicsWorld { ... }
```

The bodies and colliders of a simulation. A pointer to a body or collider stays valid until it is destroyed (they live in chunks that never move).

Ids are handed out in the order of the calls, reusing the most recently freed slot first, so two worlds built by the same calls have the same ids; the ECS sync (`SyncBodies`) makes its calls in entity order for that reason. | Ownership | owns its bodies and colliders. |
