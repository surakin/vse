Compound shapes (Phase 25 Day 383): several shapes on one body, each with a local transform, a material and its own group and mask. The mass, the centre of mass and the inertia of the whole are computed once when the compound is made.

The contact solver of the physics module (Phase 25 Day 384): sequential impulses with warm starting. Contacts become rows (a normal and two friction rows per point); the rows are solved in a fixed order, so the result does not depend on the order the narrow phase produced the manifolds in. Only `+ - * /` and `Sqrt` are used.

The static triangle mesh of a collider (Phase 25 Day 382): an immutable, shared mesh with a bounding-volume hierarchy over its triangles (`spatial::StaticBvh`), face normals and the triangle across each edge, and the library a world keeps its meshes in.

## `Collide(const Shape&,const Pose&,const Shape&,const Pose&,f32,ContactManifold*,const HullLibrary*,const MeshLibrary*,const CompoundLibrary*)` {#physics-collide-const-shape-amp-const-pose-amp-const-shape-amp-const-pose-amp-f32-contactmanifold-star-const-hulllibrary-star-const-meshlibrary-star-const-compoundlibrary-star}

`function physics::Collide` — defined in `engine/physics/collide.h`

```cpp
CollideResult Collide(const Shape& a, const Pose& pose_a, const Shape& b, const Pose& pose_b, f32 margin, ContactManifold* manifold, const HullLibrary* hulls = nullptr, const MeshLibrary* meshes = nullptr, const CompoundLibrary* compounds = nullptr);
```

Finds the contact between two shapes, the one entry point of the narrow phase.

The table, by the kinds of A and B (either order; the result is the same as for the other order, flipped): every pair of sphere, capsule and box is built by a closed form or the separating axis (Days 379-380) and every pair with a convex hull by GJK and EPA (Day 381). A pair without a test returns `Unsupported` and leaves the manifold alone. Only `+ - * /` and `Sqrt` are used, so the result is bit-identical on every machine.

| Field | Value |
|---|---|
| Parameter `a` | shape A. |
| Parameter `pose_a` | where A is. |
| Parameter `b` | shape B. |
| Parameter `pose_b` | where B is. |
| Parameter `margin` | the contact margin, at least 0: shapes apart by less than this still make a contact, with a negative depth. |
| Parameter `manifold` | receives the contact when the result is `Contact`; not null. Its friction and restitution are not touched. |
| Parameter `hulls` | the library the hull shapes' ids refer to; may be null when neither shape is a hull (a hull that is not in it makes the result `None`). |
| Parameter `meshes` | the library the mesh shapes' ids refer to; may be null when neither shape is a mesh (a mesh that is not in it gives `None`). A mesh against a mesh is `Unsupported`. |
| Parameter `compounds` | the library the compound shapes' ids refer to; may be null when neither shape is a compound (a compound that is not in it gives `None`). A compound is collided child by child and the contacts merge (their feature ids carry the child indices). |
| Returns | `Contact`, `None` or `Unsupported`. |
| Fails | an invalid shape returns `None`. |
| Ownership | `manifold` is the caller's and the libraries are borrowed; nothing is kept. |

Hashes the results of a fixed set of expressions that a changed rounding, contraction or flush mode would change.

## `StateHasher` {#physics-statehasher}

`class physics::StateHasher` — defined in `engine/physics/state_hash.h`

```cpp

```

A running FNV-1a 64-bit hash of what is fed to it, byte by byte.

Every word is fed in **little-endian byte order** whatever the machine's own order, so equal states give equal hashes everywhere. A float is hashed by its bit pattern with **-0.0 written as +0.0** (a sign of zero that depends on the order of independent operations is not a state difference); a NaN or an infinity is hashed as it is and makes `Valid()` false, because a simulation that produced one has failed. ## `SyncBodies(ecs::World&,PhysicsWorld&)` {#physics-syncbodies-ecs-world-amp-physicsworld-amp}

`function physics::SyncBodies` — defined in `engine/physics/sync.h`

```cpp
SyncReport SyncBodies(ecs::World& ecs, PhysicsWorld& physics);
```

Makes the physics world follow the ECS world.

It destroys the bodies of entities that are gone or lost their `RigidBody` or `Collider`, updates a body whose components changed, and creates a body for every new entity.

Entities are visited in entity order (index, then generation), not in chunk order, so two worlds built the same way get the same body ids. A new body starts at the entity's `LocalTransform` and `Velocity` (optional); an entity with a `Parent` is not simulated (a body has no parent). The call changes the ECS world's structure (it adds and removes `BodyLink`), so it runs between iterations, at a sync point.

| Field | Value |
|---|---|
| Parameter `ecs` | the ECS world. |
| Parameter `physics` | the physics world. |
| Returns | what was done. |
| Fails | an entity with invalid components is counted in `refused` and skipped. |
| Aborts | called while the ECS world is being iterated. |
