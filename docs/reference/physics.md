Hashes the results of a fixed set of expressions that a changed rounding, contraction or flush mode would change.

The set holds sums and products that a fused multiply-add rounds differently, a chain of `Sqrt`, conversions between integers and floats, and denormal inputs and results. Every operation is one IEEE 754 defines exactly (`+ - * / Sqrt`, conversions), so the value is the same on every machine and every compiler whose flags follow the rules; the tests compare it with a committed constant and the Windows and macOS machines compare it with the same constant.

## `StateHasher` {#physics-statehasher}

`class physics::StateHasher` — defined in `engine/physics/state_hash.h`

```cpp
class StateHasher { ... }
```

A running FNV-1a 64-bit hash of what is fed to it, byte by byte.

Every word is fed in **little-endian byte order** whatever the machine's own order, so equal states give equal hashes everywhere. A float is hashed by its bit pattern with **-0.0 written as +0.0** (a sign of zero that depends on the order of independent operations is not a state difference); a NaN or an infinity is hashed as it is and makes `Valid()` false, because a simulation that produced one has failed. Nothing but the words fed is hashed: no padding, no pointers.

| Field | Value |
|---|---|
| Thread-safety | thread-compatible; one hasher belongs to one thread. |
| Ownership | plain value; owns nothing. |
