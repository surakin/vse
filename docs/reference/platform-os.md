Exit/Write/Read/Open/Close/Lseek keep POSIX-shaped signatures; the implementation lives per platform.

```cpp
void StashNativeCommandLine(int argc, char** argv);
```

Records the process `argc`/`argv` so [`os::CommandLine::FromNative`](#os-commandline-fromnative-allocator-amp) can read them later.

Call once from the program entry point before `FromNative`. On platforms that source arguments another way this is a no-op.

| Thread-safety | not-thread-safe. Call before any other thread reads the command line. |
| Ownership | `argv` stays owned by the caller and must outlive every later `FromNative` call. |

## `CommandLine` {#os-commandline}

`class os::CommandLine` — defined in `engine/foundation/os/command_line.h`

```cpp
template <typename Allocator>
class CommandLine { ... }
```

Parsed command line: program name, positional arguments and `--name[=value]` flags.

Tokens starting with `--` and longer than two characters are flags; a flag with `=` carries a value. All other tokens are positional arguments. Repeating a flag keeps the last occurrence. All strings are copied, so the original `argv` need not outlive the object.

| Field | Value |
|---|---|
| Thread-safety | thread-compatible. Concurrent const access is safe; construction is not synchronized. |
| Ownership | owns copies of all strings, allocated from the allocator passed at construction, which must outlive this object. |

## `kMaxPathBytes` {#os-kmaxpathbytes}

`variable os::kMaxPathBytes` — defined in `engine/foundation/os/os.h`

```cpp
constexpr usize kMaxPathBytes;
```

Maximum path length in bytes that [`os::Open`](#os-open-stringview-int-int) and [`os::LoadLibrary`](#os-loadlibrary-stringview) accept.

Paths are copied into a null-terminated buffer of this size before being passed to the OS; a path that does not fit makes the call fail instead of being truncated.
