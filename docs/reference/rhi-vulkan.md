## `GetBarrierScopes(ResourceState,ResourceState,bool,BarrierScopes*)` {#rhi-vulkan-getbarrierscopes-resourcestate-resourcestate-bool-barrierscopes-star}

`function rhi::vulkan::GetBarrierScopes` — defined in `engine/rhi/vulkan/vk_barrier.h`

```cpp
bool GetBarrierScopes(ResourceState before, ResourceState after, bool is_image, BarrierScopes* out);
```

Looks up the barrier scopes for a state transition of a buffer or an image.

A transition from `Undefined` waits on all earlier work and, for an image, discards the contents (old layout `UNDEFINED`). `Undefined` is never a valid destination. Buffers support `VertexBuffer`, `IndexBuffer`, `UniformBuffer`, `ShaderRead`, `ShaderWrite`, `CopySrc` and `CopyDst`; images support every state except the first three.

| Field | Value |
|---|---|
| Parameter `before` | the state the resource is in. |
| Parameter `after` | the state it moves to. |
| Parameter `is_image` | whether the resource is an image rather than a buffer. |
| Parameter `out` | receives the scopes; must not be null. |
| Returns | true if the transition is valid for that kind of resource. |
| Fails | returns false, leaving `out` unchanged, for an unsupported state or an `Undefined` destination. |

## `SelectPhysicalDevice(const PhysicalDeviceInfo*,usize,bool,const char*)` {#rhi-vulkan-selectphysicaldevice-const-physicaldeviceinfo-star-usize-bool-const-char-star}

```cpp

```

Chooses the physical device to use.

Unsuitable devices are skipped; the rest are ranked by [`rhi::vulkan::GpuKind`](#rhi-vulkan-gpukind) (discrete best), ties going to the earlier device. The override must match a suitable device or selection fails. The whole ranking and every rejection reason is logged on `LogRhi`.

| Field | Value |
|---|---|

| Parameter `count` | number of candidates; at most `kMaxPhysicalDevices` are considered. |
| Parameter `presentable` | whether the device must be able to present. |
| Parameter `override_text` | the value of `ENGINE_RHI_GPU`, or null/empty for none. |
| Returns | the index of the chosen device, or -1. |
| Fails | returns -1 if no device is suitable or the override matches no suitable device. |

## `MemoryAllocator` {#rhi-vulkan-memoryallocator}

`class rhi::vulkan::MemoryAllocator` — defined in `engine/rhi/vulkan/vk_memory.h`

```cpp
class MemoryAllocator { ... }
```

Carves device memory into suballocations from large blocks.

Per memory type there are two pools (linear and optimal resources), each a list of blocks managed by a [`rhi::vulkan::FreeList`](#rhi-vulkan-freelist). Requests larger than a fraction of the block size, and requests marked dedicated, get their own memory object. An emptied block is released unless it is the only empty block of its pool (one spare is kept). Host-visible blocks are mapped once, when created.

Failure policy: allocation never aborts. It returns an empty [`rhi::vulkan::MemoryAllocation`](#rhi-vulkan-memoryallocation) and reports whether the device or the host ran out of memory, so the resource creation above it can fail with a log line. Freeing an allocation twice, or one that is not from this allocator, is a programming error and aborts.

| Field | Value |
|---|---|
| Thread-safety | thread-safe. Calls are serialized by an internal mutex, including the backend's. |
| Ownership | borrows the backend, which must outlive it; frees every block on destruction. |
