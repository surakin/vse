Plain tables of Vulkan function pointers, resolved once per global/instance/device scope.

Vulkan loader access: `libvulkan.so.1` opened at runtime, so nothing links against Vulkan.

`VkResult` naming, classification and a logging check helper.

## `CheckInstanceVersion(const VkGlobalFns&,u32*)` {#rhi-vulkan-checkinstanceversion-const-vkglobalfns-amp-u32-star}

`function rhi::vulkan::CheckInstanceVersion` — defined in `engine/rhi/vulkan/vk_functions.h`

```cpp
bool CheckInstanceVersion(const VkGlobalFns& fns, u32* out_version);
```

Reads the instance-level Vulkan version and checks it against [`rhi::vulkan::kRequiredVulkanVersion`](#rhi-vulkan-krequiredvulkanversion).

A loader without `vkEnumerateInstanceVersion` is Vulkan 1.0 and is rejected. The version is logged. This checks the loader's instance version only; a physical device can still be older, so device selection (Day 50) checks `VkPhysicalDeviceProperties::apiVersion` as well.

| Field | Value |
|---|---|
| Parameter `fns` | a loaded global table. |
| Parameter `out_version` | receives the version (`VK_MAKE_API_VERSION` encoding) when the query succeeds, 1.0 for a 1.0 loader; may be null. |
| Returns | true if the version is at least 1.3. |
| Fails | returns false and logs "driver too old" if the version is below 1.3, or logs the failed query and returns false if `vkEnumerateInstanceVersion` itself fails. |

## `VulkanLoader` {#rhi-vulkan-vulkanloader}

`struct rhi::vulkan::VulkanLoader` — defined in `engine/rhi/vulkan/vk_loader.h`

```cpp
struct VulkanLoader { ... }
```

A Vulkan loader library that has been opened.

The library handle is intentionally never unloaded: Vulkan drivers and layers keep threads and global state alive past `vkDestroyInstance`, and unloading their code from under them crashes at process exit. The handle therefore has no owner and no destructor. Opening the same library again returns the same mapping, so repeated loads do not accumulate.

| Field | Value |
|---|---|
| Thread-safety | thread-compatible plain data; the function pointer is immutable once set. |

## `LoadVulkanLoader(VulkanLoader*)` {#rhi-vulkan-loadvulkanloader-vulkanloader-star}

`function rhi::vulkan::LoadVulkanLoader` — defined in `engine/rhi/vulkan/vk_loader.h`

```cpp
LoaderStatus LoadVulkanLoader(VulkanLoader* out);
```

Opens the Vulkan loader library and resolves `vkGetInstanceProcAddr`.

The library is `libvulkan.so.1` unless [`rhi::vulkan::kVulkanLibraryEnvVar`](#rhi-vulkan-kvulkanlibraryenvvar) names another path, which is how tests simulate a machine without Vulkan. The override is a development aid and grants nothing the process environment does not already (`LD_PRELOAD` and `VK_ICD_FILENAMES` redirect the loader the same way). The reason for a failure is logged on `LogRhi`.

| Field | Value |
|---|---|
| Parameter `out` | receives the loader on success; left untouched otherwise. Must not be null. |
| Returns | `LoaderStatus::Ok` on success. |
| Fails | `NoLoader` if the library cannot be opened; `BadLoader` if it lacks `vkGetInstanceProcAddr`. |
| Thread-safety | thread-safe against other calls; it reads the environment, so do not change the environment concurrently. May be called repeatedly. |


Classifies a `VkResult`; see [`rhi::vulkan::VkResultClass`](#rhi-vulkan-vkresultclass).

Unknown negative values are `Fatal`, unknown non-negative ones `Success`. A caller that needs the exact value (say `VK_ERROR_OUT_OF_DEVICE_MEMORY`) stores the `VkResult` first and classifies that.
