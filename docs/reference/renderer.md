## `RenderLogV(LogVerbosity,const char*,...)` {#renderer-renderlogv-logverbosity-const-char-star}

`function renderer::RenderLogV` — defined in `engine/renderer/renderer_log.h`

```cpp
void RenderLogV(LogVerbosity level, const char* fmt, ...) __attribute__((format(printf, 2, 3)));
```

Logs a printf-style message on the foundation's `LogRender` channel using a 512-byte stack buffer and no allocator.

The renderer reports environment problems (a format the device cannot render to, a failed pipeline), never per-draw events. It shares `LogRender` with the rest of the engine, so `--log-level` applies. Output longer than the buffer is truncated, and nothing is formatted when the level is filtered out.

| Field | Value |
|---|---|
| Parameter `level` | verbosity of the message. |
| Parameter `fmt` | printf format string; the arguments follow it. |
| Thread-safety | thread-safe. Formats into a stack buffer and logs through the shared sink. |
