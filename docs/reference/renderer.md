# The renderer

_Generated by docgen. Do not edit._

**Headers:** `engine/renderer/renderer_info.h`, `engine/renderer/renderer_log.h`, `engine/renderer/shader_permutation.h`, `engine/renderer/shader_reflection.h`

Identification of the renderer library; the first real symbol of Phase 4 (the camera and scene arrive on Day 73).

The renderer: a deferred, render-graph-driven renderer built on the RHI.

Shader permutations: one Slang source built offline into several SPIR-V modules, one per option combination.

A shader declares its options in a `// permutation-options: A B C` comment and uses them as compile-time defines (`#if A`); a manifest next to it (`<name>.perm`) lists which combinations to build. The `shader_mint` tool compiles each listed key, drops duplicate modules, and commits the result as `<name>.perm.inc`: a [`renderer::ShaderPermutations`](#renderer-shaderpermutations) table that [`renderer::FindPermutation`](#renderer-findpermutation-const-shaderpermutations-amp-permutationkey-reflectionerror-star) searches at run time. A key that was not built is an error naming the shader and the key, never a silent fallback.

What a compiled shader says about itself: its stage, bindings, uniform and push-constant block layouts, vertex inputs and compute local size. The offline `shader_mint` tool extracts it from `slangc` output into a compact blob committed as `shaders/<name>.refl.inc`; the renderer parses the blob and builds bind group layouts and vertex layouts from it instead of writing them a second time by hand.
