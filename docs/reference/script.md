## `State` {#script-state}

`class script::State` — defined in `engine/script/backend.h`

```cpp
class State { ... }
```

One language state: its globals, its loaded chunks, its memory.

**A state is used by one thread at a time**: it is created owned by the thread that created it, and the owner changes only through [`State::HandOver`](#script-state-handover) and [`State::Acquire`](#script-state-acquire), at a synchronization point the caller provides (a job boundary). Every public call checks the owner in builds with debug checks.

A backend derives from `State` and implements the `Do...` functions; the public functions check the thread rules and call them.

| Field | Value |
|---|---|
| Thread-safety | not-thread-safe by design: one owner thread at a time; the owner check and handover are the only members safe to call from any thread. |
| Ownership | the state owns its language runtime; destroying it closes the runtime. |

## `ScriptWorld` {#script-scriptworld}

## `Value` {#script-value}

`class script::Value` — defined in `engine/script/value.h`

```cpp
class Value { ... }
```

One script value: nil, a boolean, an integer, a float, text, a vector of two to four floats, a rotation, an entity id, a byte blob, an array or a map.

A value owns everything it holds and is copied deeply, so it can be handed to another thread or another state. Nesting is bounded ([`kMaxValueDepth`](#script-kmaxvaluedepth), [`kMaxContainerItems`](#script-kmaxcontaineritems)) when children are added, so copying, comparing and destroying a value use bounded recursion whatever came in. Size and text limits for hostile input are applied by [`Value::Check`](#script-value-check-const-valuelimits-amp-const) at the boundary.

| Field | Value |
|---|---|
| Thread-safety | thread-compatible: a value is not shared between threads, it is copied. |
| Ownership | owns its text, blob, items and keys; copies are deep. |
