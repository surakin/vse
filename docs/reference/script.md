## `State` {#script-state}

`class script::State` — defined in `engine/script/backend.h`

```cpp
class State { ... }
```

One language state: its globals, its loaded chunks, its memory.

**A state is used by one thread at a time**: it is created owned by the thread that created it, and the owner changes only through [`State::HandOver`](#script-state-handover) and [`State::Acquire`](#script-state-acquire), at a synchronization point the caller provides (a job boundary). Every public call checks the owner in builds with debug checks.

A backend derives from `State` and implements the `Do...` functions; the public functions check the thread rules and call them.

| Field | Value |
|---|---|
| Thread-safety | not-thread-safe by design: one owner thread at a time; the owner check and handover are the only members safe to call from any thread. |
| Ownership | the state owns its language runtime; destroying it closes the runtime. |
