# Text

_Generated by docgen. Do not edit._

**Headers:** `engine/text/library.h`

The text module's view of the FreeType library: its version, and the allocation counts of a library session.

FreeType (vendored under `third_party/freetype/`, `PLAN.md` assumption #17) is named in exactly one file of the engine, `engine/text/font_freetype.cpp` (the `platform_neutral_check` library boundary); everything else uses the types of this module. Every block FreeType allocates comes from the engine's heap through a counting `FT_Memory`, so the engine's allocation accounting stays true and a failed allocation is testable.

## `ProbeLibrary(LibraryVersion*,LibraryAllocationStats*)` {#text-probelibrary-libraryversion-star-libraryallocationstats-star}

`function text::ProbeLibrary` — defined in `engine/text/library.h`

```cpp
bool ProbeLibrary(LibraryVersion* version, LibraryAllocationStats* stats);
```

Starts a FreeType library with the engine's allocator and its module list, reads the version and shuts it down.

| Field | Value |
|---|---|
| Parameter `version` | receives the library's version; may be null. |
| Parameter `stats` | receives the session's allocation counts; may be null. |
| Returns | true when the library started and shut down cleanly; false when FreeType refused to start or reported an error while shutting down. |
| Fails | returns false, leaving `version` and `stats` unchanged, when FreeType reports an error at startup (out of memory is the realistic cause); an error while shutting down also returns false, with both outputs filled in. |
| Thread-safety | thread-safe; every call is its own library instance. |
| Ownership | nothing is retained; the library is destroyed before the call returns. |
