# Text

_Generated by docgen. Do not edit._

**Headers:** `engine/text/font.h`, `engine/text/glyph_atlas.h`, `engine/text/library.h`, `engine/text/shelf_packer.h`

Font faces: loading, sizing, glyph lookup, metrics, kerning and outlines (Phase 14).

A [`text::FontLibrary`](#text-fontlibrary) owns one FreeType library (and the counting allocator behind it); each [`text::Font`](#text-font) is one face opened from it at one pixel size. FreeType is named only in `font_freetype.cpp`. Errors are values ([`text::Status`](#text-status)), never exceptions. There is **no shaping**: one code point is one glyph through the font's cmap (`docs/superpowers/specs/2026-11-08-text-design.md`, section 3).

The glyph atlas (Phase 14): rasterized glyphs packed into 8-bit coverage pages held in CPU memory.

The CPU pages are the source of truth; the renderer copies them into GPU textures and can rebuild those textures from them after a device reset. There is no eviction in this version: a full page adds a page, up to a maximum, after which glyphs are refused and counted.

The text module's view of the FreeType library: its version, and the allocation counts of a library session.

FreeType (vendored under `third_party/freetype/`, `PLAN.md` assumption #17) is named in exactly one file of the engine, `engine/text/font_freetype.cpp` (the `platform_neutral_check` library boundary); everything else uses the types of this module. Every block FreeType allocates comes from the engine's heap through a counting `FT_Memory`, so the engine's allocation accounting stays true and a failed allocation is testable.

A shelf packer for glyph atlas pages (Phase 14): rectangles go left to right on shelves, a new shelf opens below when none fits.

## `Font` {#text-font}

`class text::Font` — defined in `engine/text/font.h`

```cpp
class Font { ... }
```

One font face at one pixel size.

A `Font` owns a copy of the font file's bytes (FreeType reads them for the face's whole life). It is movable, not copyable. Using one `Font` from two threads at once is not supported (`FT_Face` is not thread-safe), **including the const calls**: `Metrics`, `FindGlyph`, `Kerning` and `LoadOutline` load into the face's shared glyph slot. Use one `Font` per thread or an external lock.

| Field | Value |
|---|---|
| Thread-safety | thread-compatible. |
| Ownership | owns the face and the font bytes; borrows the [`text::FontLibrary`](#text-fontlibrary), which must outlive it. |
