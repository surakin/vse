# Text

_Generated by docgen. Do not edit._

**Headers:** `engine/text/cursor.h`, `engine/text/font.h`, `engine/text/glyph_atlas.h`, `engine/text/layout.h`, `engine/text/library.h`, `engine/text/shelf_packer.h`

Cursor positions, hit-testing, movement and selection over a [`text::TextLayout`](#text-textlayout) (Phase 14).

Offsets are byte offsets into the laid-out UTF-8 text, and the only valid cursor offsets are **grapheme boundaries**: the start of a cluster, or the length of the text. An offset inside a cluster is snapped to that cluster's start. Combining marks, ZWJ sequences and flags are one step. At a soft wrap the offset where one line ends and the next begins belongs to the later line (there is no caret affinity). Word movement is not provided (Phase 15).

Font faces: loading, sizing, glyph lookup, metrics, kerning and outlines (Phase 14).

A [`text::FontLibrary`](#text-fontlibrary) owns one FreeType library (and the counting allocator behind it); each [`text::Font`](#text-font) is one face opened from it at one pixel size. FreeType is named only in `font_freetype.cpp`. Errors are values ([`text::Status`](#text-status)), never exceptions. There is **no shaping**: one code point is one glyph through the font's cmap (`docs/superpowers/specs/2026-11-08-text-design.md`, section 3).

The glyph atlas (Phase 14): rasterized glyphs packed into 8-bit coverage pages held in CPU memory.

The CPU pages are the source of truth; the renderer copies them into GPU textures and can rebuild those textures from them after a device reset. There is no eviction in this version: a full page adds a page, up to a maximum, after which glyphs are refused and counted.

Text layout (Phase 14): UTF-8 in, positioned glyphs, grapheme clusters and lines out. No shaping, no bidirectional text, no vertical text.

Coordinates are pixels with the origin at the top-left of the first line and y growing down (as the overlay pass draws). A layout depends only on its input and the font's metrics at the style's size, and the same input gives byte-identical output.

The text module's view of the FreeType library: its version, and the allocation counts of a library session.

FreeType (vendored under `third_party/freetype/`, `PLAN.md` assumption #17) is named in exactly one file of the engine, `engine/text/font_freetype.cpp` (the `platform_neutral_check` library boundary); everything else uses the types of this module. Every block FreeType allocates comes from the engine's heap through a counting `FT_Memory`, so the engine's allocation accounting stays true and a failed allocation is testable.

A shelf packer for glyph atlas pages (Phase 14): rectangles go left to right on shelves, a new shelf opens below when none fits.

## `Font` {#text-font}

`class text::Font` — defined in `engine/text/font.h`

```cpp

```

One font face at one pixel size.

A `Font` owns a copy of the font file's bytes (FreeType reads them for the face's whole life). It is movable, not copyable. Using one `Font` from two threads at once is not supported (`FT_Face` is not thread-safe), **including the const calls**: `Metrics`, `FindGlyph`, `Kerning` and `LoadOutline` load into the face's shared glyph slot. ## `Layout(StringView,const TextStyle&,const LayoutOptions&,TextLayout*)` {#text-layout-stringview-const-textstyle-amp-const-layoutoptions-amp-textlayout-star}

`function text::Layout` — defined in `engine/text/layout.h`

```cpp
Status Layout(StringView utf8, const TextStyle& style, const LayoutOptions& options, TextLayout* out);
```

Lays out `utf8` in one style.

One code point maps to one glyph through the font's character map; a cluster of several code points yields one glyph per code point, with zero advance for combining marks, zero-width joiners and variation selectors (the no-shaping limit). Kerning from the font's `kern` table applies between neighbouring clusters on a line. `\\n`, `\\r\\n` and `\\r` end a line; a tab advances to the next tab stop; with `max_width` above 0 a line wraps after the last space (U+0020; the only break opportunities are a space and a tab, so other whitespace such as U+00A0 or U+3000 never breaks) that fits, or between clusters when a word is wider than the line (never inside a cluster). Trailing spaces never trigger a wrap and do not count towards the width.

| Field | Value |
|---|---|
| Parameter `utf8` | the text; malformed sequences become U+FFFD and are counted. |
| Parameter `style` | the font and size. |
| Parameter `options` | wrapping, line height, tabs, alignment. |
| Parameter `out` | receives the layout; cleared first. |
| Fails | `InvalidArgument` for a style with no open font, a pixel size the font refuses, a `line_height_scale` not in (0, 100] or a negative or non-finite `max_width`, text longer than 4 GiB (offsets are 32-bit); `OutOfMemory`; `out` is left empty. |
| Ownership | nothing is retained; `out` does not refer to `utf8` or the font. |
