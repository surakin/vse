# Scene bridge

_Generated by docgen. Do not edit._

**Headers:** `engine/scene/components.h`, `engine/scene/level_spawner.h`, `engine/scene/render_sync.h`, `engine/scene/scene_components.h`

Renderable components: what an entity carries so that the render sync can mirror it into a [`renderer::RenderScene`](renderer.md#renderer-renderscene).

Spawning a level into a world through the resource manager.

[`scene::SpawnLevel`](#scene-spawnlevel-asset-resourcemanager-amp-asset-resourceid-const-storage-componentregistry-amp-ecs-world-amp-storage-keyindex-amp-spawnedlevel-star) loads a level and its closure (meshes, materials, textures, skeletons, clips, included levels), creates its entities with [`asset::LoadLevelBlob`](asset.md#asset-loadlevelblob-bytespan-const-typeregistry-amp-const-storage-componentregistry-amp-ecs-world-amp-storage-keyindex-amp-leveldata-star-const-storage-codeclimits-amp), and gives each [`asset::MeshReference`](asset.md#asset-meshreference) a [`scene::MeshRenderer`](#scene-meshrenderer) that shares the manager's mesh, so the render sync draws it. The entities and the [`scene::SpawnedLevel`](#scene-spawnedlevel) go together: while the spawned level lives, what its entities use stays loaded.

The bridge from ECS entities to the renderer: a system that mirrors renderable entities into a [`renderer::RenderScene`](renderer.md#renderer-renderscene) and one that builds the camera.

The scene's components in the storage registry: [`scene::LightSource`](#scene-lightsource), [`scene::Camera`](#scene-camera) and [`scene::Hidden`](#scene-hidden), so that levels, saves and scripts (`component.add(e, "light_source", {...})`) can name them. [`scene::MeshRenderer`](#scene-meshrenderer) holds a shared GPU mesh, which has no stored form; a mesh is named by its asset id and built by the level spawner or, for scripts, by the resource bindings.

```cpp
asset::Status SpawnLevel(asset::ResourceManager& manager, asset::ResourceId id, const storage::ComponentRegistry& registry, ecs::World& world, storage::KeyIndex& index, SpawnedLevel* out);
```

Loads the level `id` through `manager` and creates its entities (and those of the levels it includes, first) in `world`; every `mesh_reference` component gets a [`scene::MeshRenderer`](#scene-meshrenderer) whose mesh is the manager's and whose material is the material system's slot of the referenced material; an entity with a local transform also gets the world transform the transform system fills (a level does not store derived state). The levels' dependencies must load as the GPU types ([`asset::RegisterGpuLoaders`](asset.md#asset-registergpuloaders-resourcemanager-star-gpuassetcontext-star)).

| Field | Value |
|---|---|
| Parameter `manager` | the manager with the CPU and GPU loaders registered. |
| Parameter `id` | the level. |
| Parameter `registry` | the components (builtin, level and the game's). |
| Parameter `world` | receives the entities; it must hold none of this level's keys. |
| Parameter `index` | the keys of `world`; updated. |
| Parameter `out` | receives the references; replaced. |
| Fails | the failures of [`asset::ResourceManager::Load`](asset.md#asset-resourcemanager-load-resourceid-handle-lt-t-gt-star-loadfailure-star) for the level or anything it needs (`MissingDependency`, `DependencyTypeMismatch`, ...), and of [`asset::LoadLevelBlob`](asset.md#asset-loadlevelblob-bytespan-const-typeregistry-amp-const-storage-componentregistry-amp-ecs-world-amp-storage-keyindex-amp-leveldata-star-const-storage-codeclimits-amp) (`Exists` for a key already in the world); `LimitExceeded` for includes nested deeper than 16 levels; on any failure the entities made so far are destroyed and `*out` holds nothing. |

## `MakeRenderSyncSystem(const char*)` {#scene-makerendersyncsystem-const-char-star}

`function scene::MakeRenderSyncSystem` — defined in `engine/scene/render_sync.h`

```cpp
ecs::SystemDesc MakeRenderSyncSystem(const char* name);
```

The render sync system: it mirrors entities into the linked `RenderScene` and touches it only for what changed.

It keeps a [`scene::RenderHandle`](#scene-renderhandle) on every mirrored entity:

- an entity with `MeshRenderer` and `WorldTransform` (and no `RenderHandle`) gets an object; one with `LightSource` (and no `MeshRenderer`) gets a light;
- a changed `WorldTransform` moves the object (or recomputes the light), only when the matrix differs from the scene's;
- a changed `MeshRenderer` re-adds the object when the mesh or material differs, or updates the flags; the `Hidden` tag maps to `ObjectFlags::kHidden`;
- a destroyed entity (found through the world's removal log of `RenderHandle`) or one that lost its `MeshRenderer` or `LightSource` has its object or light removed;
- a full scene is a counted refusal, retried every frame; an unusable mesh or light is counted as invalid on each frame it is looked at.

Needs the resources [`scene::SceneLink`](#scene-scenelink) and [`scene::SceneSyncReport`](#scene-scenesyncreport) in the world. Register it in `ecs::kRender`; an entity does not mirror both a mesh and a light. The sync holds a reference to each object's mesh asset, so the geometry outlives its scene entry.

| Field | Value |
|---|---|
| Parameter `name` | the system's name, copied by the schedule. |
| Returns | the system description to `Schedule::Add`. |
| Aborts | the linked scene changes between frames; a needed resource is missing. |
| Thread-safety | thread-compatible; it writes the render scene, so it must not run while the renderer reads it. |
| Ownership | the system owns its queries and the references it keeps; the scene is borrowed. |
