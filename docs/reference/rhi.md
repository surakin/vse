
Logs a printf-style message on [`rhi::LogRhi`](#rhi-logrhi) using a 512-byte stack buffer and no allocator.

RHI logging reports environment problems, validation output and device diagnostics, never per-draw events. Output longer than the buffer is truncated, and nothing is formatted when the level is filtered out.

|---|---|
| Parameter `level` | verbosity of the message. |
| Parameter `fmt` | printf format string; the arguments follow it. |
| Thread-safety | thread-safe. Formats into a stack buffer and logs through the shared sink. |
