_Generated by docgen. Do not edit._

**Headers:** `engine/foundation/log/assert.h`, `engine/foundation/log/log.h`

Assertion macro and failure hook, split out of log.h so low-level headers can assert without depending on the string module.

Channel-based logging with per-channel verbosity, overridable from a config file.

Needs no allocator; log lines and config parsing use fixed-size stack buffers.

## `LogChannel` {#logchannel}


A named source of log messages with its own verbosity threshold and enable flag.

Every constructed channel links itself into a global registry (used by [`LogChannel::Find`](#logchannel-find-stringview)), so channels are meant to be long-lived globals and must never be destroyed while the program can still look them up.

| Field | Value |
|---|---|
| Thread-safety | not-thread-safe. Construct channels during static initialization; the verbosity and enable setters are unsynchronized. |
| Ownership | does not own `name`; the string must outlive the channel. |

## `LoadConfig(const char*)` {#loadconfig-const-char-star}

`function LoadConfig` — defined in `engine/foundation/log/log.h`

```cpp
bool LoadConfig(const char* path);
```

Applies per-channel overrides from a `key=value` config file.

Lines have the form `ChannelName.verbosity=Level` (`Error`, `Warn`, `Info`, `Debug` or `Trace`) or `ChannelName.enabled=true|false` (`1` also means true). Unknown channels, attributes and malformed lines are skipped silently. An unrecognized verbosity name is not skipped: it sets the channel to `Warn`. Only the first 4096 bytes of the file are read.

| Field | Value |
|---|---|
| Parameter `path` | path of the config file, NUL-terminated. |
| Returns | true if the file was opened and had content; false otherwise. |
| Fails | returns false if the file cannot be opened or is empty. A missing config file is not an error for the caller. |
| Thread-safety | not-thread-safe. Modifies channel state without synchronization. |
