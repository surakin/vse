# Foundation: Logging and Assertions

_Generated by docgen. Do not edit._

**Headers:** `engine/foundation/log/assert.h`, `engine/foundation/log/diagnostics_hooks.h`, `engine/foundation/log/log.h`, `engine/foundation/log/log_device.h`, `engine/foundation/log/tty_log_device.h`

The assertion family and its failure handler, split out of log.h so low-level headers can assert without depending on the string module.

- [`ENGINE_ASSERT`](#engine-assert): a contract the code relies on; always checked, fatal.
- [`ENGINE_ENSURE`](#engine-ensure): a condition that should hold but that the caller can survive; reported once per call site, then execution continues.
- [`ENGINE_VERIFY`](#engine-verify): like assert but the expression is always evaluated and the check exists only in debug builds.
- [`ENGINE_CHECK_SLOW`](#engine-check-slow): an expensive check, compiled out unless slow checks are on.
- [`ENGINE_UNREACHABLE`](#engine-unreachable) and [`ENGINE_NOT_IMPLEMENTED`](#engine-not-implemented).

Every failure goes to one handler (see [`SetAssertHandler`](#setasserthandler-asserthandler)), which tests, tools and the crash handler can replace.

Two registrations through which the debugging module (layer 7) reaches code below it without being included by it.

- [`FailureReportHooks`](#failurereporthooks): what the default assert handler and the error-log trace add to a bare message (a stack trace, the crash context, a look at the debugger).
- [`SetThreadStartHook`](#setthreadstarthook-threadstarthook) and [`AddThreadEndHook`](#addthreadendhook-threadendhook): what a thread does first so a crash on it is reported by name (registration with the crash handler), and what it gives back last.

`debug::InstallDiagnosticsHooks` (called by `debug::InitDebugFacilities`) installs both. Until then the base behavior is complete on its own: a failed assert prints its message line and aborts, an ensure prints its line and continues, and a thread starts unregistered.

Channel-based logging with per-channel verbosity (the settings system overrides it, `log.<channel>.verbosity`).

Needs no allocator; log lines and config parsing use fixed-size stack buffers.

Log devices: where the lines [`Log`](#log-logchannel-amp-logverbosity-stringview) emits go (Maintenance: log devices).

A device is an object that receives every line a channel lets through: standard output (the default), a coloured terminal, a file, a window, the network. [`Log`](#log-logchannel-amp-logverbosity-stringview) writes each line to the **console device** (chosen by [`SetConsoleLogMode`](#setconsolelogmode-consolelogmode)) and to every device added with [`AddLogDevice`](#addlogdevice-logdevice-star-logverbosity), at most [`kMaxLogDevices`](#kmaxlogdevices) of them.

The crash and assert reports do not go through devices: they write straight to the log core's write sink, so they stay async-signal-safe and plain. Needs no allocator.

Prints one line to the write sink (file descriptor 1), `ASSERT FAILED: file:line function: condition: message` (the leading words depend on the kind; empty parts are left out; truncated at 512 bytes, always ending in a newline), then returns [`AssertAction::Break`](#assertaction-break) if a debugger is attached, otherwise [`AssertAction::Abort`](#assertaction-abort) for every kind except [`AssertKind::Ensure`](#assertkind-ensure), which gets [`AssertAction::Continue`](#assertaction-continue).

## `ENGINE_ENSURE` {#engine-ensure}

`macro ENGINE_ENSURE` — defined in `engine/foundation/log/assert.h`

```cpp
#define ENGINE_ENSURE(cond, msg)
```

Evaluates `cond` once and returns it; if it is false, reports the failure once for this call site and returns false.

Use it where the condition should hold but the caller can recover: `if (!ENGINE_ENSURE(p != nullptr, "no p")) return;`. The first failure at each call site goes to the assert handler (the default handler prints a line and the program goes on); later failures there are only counted. See [`ForEachFailedEnsure`](#foreachfailedensure-ensurevisitor-void-star). Not usable in a `constexpr` function.

|---|---|
| Parameter `cond` | expression; evaluated exactly once. |
| Parameter `msg` | a string literal describing the condition. |
| Returns | the value of `cond`. |

## `ENGINE_VERIFY` {#engine-verify}

`macro ENGINE_VERIFY` — defined in `engine/foundation/log/assert.h`

```cpp
#define ENGINE_VERIFY(expr, msg)
```

Evaluates `expr` in every configuration and, when [`ENGINE_DEBUG_CHECKS`](#engine-debug-checks) is 1, checks that it is true.

[`ENGINE_DEBUG_CHECKS`](#engine-debug-checks) is a per-translation-unit setting, so this macro, [`ENGINE_CHECK_SLOW`](#engine-check-slow) and [`ENGINE_UNREACHABLE`](#engine-unreachable) must not be used in header-inline code (the same inline function would differ between translation units); a gate enforces it. Use [`ENGINE_ASSERT`](#engine-assert) or [`ENGINE_ENSURE`](#engine-ensure) in headers.

For a call that must run for its effect but whose result should be true: `ENGINE_VERIFY(Init(), "init failed")`. In a build without debug checks the expression still runs and the result is ignored.

| Field | Value |
|---|---|
| Parameter `expr` | expression; evaluated exactly once in every configuration. |
| Parameter `msg` | a string literal describing the failure. |
| Aborts | debug checks are on and `expr` evaluates to false. |

## `ReadRecentLogLines(RecentLogLineFn,void*,usize)` {#readrecentloglines-recentloglinefn-void-star-usize}

`function ReadRecentLogLines` — defined in `engine/foundation/log/log.h`

```cpp
void ReadRecentLogLines(RecentLogLineFn callback, void* context, usize max_lines = 0);
```

Calls `callback` for the most recent log lines, oldest first, at most [`kLogRingSlots`](#klogringslots) of them.

Every line [`Log`](#log-logchannel-amp-logverbosity-stringview) emits is also kept in a ring in memory, so a crash report can show what the program said last. A slot that is being overwritten while it is read is skipped, so every line delivered is whole. Reads no file and allocates nothing.

| Field | Value |

| Parameter `callback` | called once per line. |
| Parameter `context` | passed through to `callback`; borrowed for the call. |
| Parameter `max_lines` | deliver at most this many of the newest lines (0 means no limit beyond the ring size). |
| Thread-safety | thread-safe and async-signal-safe: lock-free, concurrent with any number of [`Log`](#log-logchannel-amp-logverbosity-stringview) calls. |
