```cpp
AudioEventReport PumpPlacedSounds(ecs::World* world, const audio::SpatialAudio* spatial, VoiceTable* voices, script::ScriptRuntime* runtime);
```

Ends the placed sounds that are over (`audio.play` with `position` or `entity`): a one-shot that played to its end, a sound whose entity or `AudioSource` went (the script's `audio.stop` does that), and a transient one-shot nobody could hear. Each gets an `on_voice_end` event (`reason` is `"finished"`, or `"stopped"` for a sound whose entity or source went), and a transient sound's entity is destroyed. ## `PumpAudioEvents(audio::Mixer*,VoiceTable*,script::ScriptRuntime*)` {#script-media-pumpaudioevents-audio-mixer-star-voicetable-star-script-scriptruntime-star}

`function script_media::PumpAudioEvents` — defined in `engine/script_media/audio_bindings.h`

```cpp
AudioEventReport PumpAudioEvents(audio::Mixer* mixer, VoiceTable* voices, script::ScriptRuntime* runtime);
```

Tells scripts which of their voices ended, from the mixer's events.

The payload of `on_voice_end` is `voice` (the handle) and `reason` (`"finished"`, `"stopped"` or `"stolen"`). The handle is then forgotten. Call it at the sync point, on the thread that merges, between script ticks. With an offline mixer the events of the blocks rendered so far arrive, in block order; with a device the timing follows the audio thread, so a game that needs repeatable event timing drives an offline mixer.

## `VoiceTable` {#script-media-voicetable}

`class script_media::VoiceTable` — defined in `engine/script_media/audio_services.h`

```cpp
class VoiceTable { ... }
```

The handles of the voices scripts started.

A script gets its handle when it calls `audio.play`, before the voice exists: the handle is made of the tick and the partition's reserved placeholder number, so it depends only on the script's own calls (never on the thread count), and the merge binds it to the mixer's [`audio::VoiceId`](audio.md#audio-voiceid). An entry goes when `PumpAudioEvents` reads the voice's end from the mixer, so a host calls that once a frame (a host that never does keeps one entry per voice ever started, and the handles of ended voices stay valid).

| Field | Value |
