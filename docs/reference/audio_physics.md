## `PhysicsOcclusion` {#audio-physics-physicsocclusion}

`class audio_physics::PhysicsOcclusion` — defined in `engine/audio_physics/physics_occlusion.h`

```cpp
class PhysicsOcclusion final : public audio::OcclusionQuery { ... }
```

Casts a ray from the emitter to the listener through the physics world and turns what it crosses into an occlusion value. The thickness of each collider is measured with two rays (one from each end: the entry of the second is the exit of the first), summed with the layer's absorption; no diffraction around the obstacle is modelled (the guide says so). The queries scan the world's colliders, so a thousand emitters are fine and a hundred thousand are not.

| Field | Value |
|---|---|
| Thread-safety | thread-compatible; call it between physics steps, from the control thread. |
| Ownership | borrows the world, which must outlive the query. |
