## `MemoryOrder` {#memoryorder}

`enum MemoryOrder` — defined in `engine/foundation/sync/atomic.h`

```cpp
enum class MemoryOrder : u8 { ... }
```

How an atomic operation orders the memory accesses around it (`std::memory_order`).

`Relaxed` orders nothing; `Acquire` on a load and `Release` on a store pair up so what the writer did before the store is visible after the load; `AcqRel` does both for a read-modify-write; `SeqCst` is a single total order and the default. `Consume` is treated as `Acquire`, as every implementation does.

| Enumerator | Value | Description |
|---|---|---|
| <a id="memoryorder-relaxed"></a>`Relaxed` |  | No ordering beyond the atomicity of the operation itself. |
| <a id="memoryorder-consume"></a>`Consume` |  | Treated as `Acquire`. |
| <a id="memoryorder-acquire"></a>`Acquire` |  | A load that sees a `Release` store also sees everything written before that store. |
| <a id="memoryorder-release"></a>`Release` |  | A store that publishes everything written before it to a thread that loads it with `Acquire`. |
| <a id="memoryorder-acqrel"></a>`AcqRel` |  | Both `Acquire` and `Release`, for a read-modify-write. |
| <a id="memoryorder-seqcst"></a>`SeqCst` |  | A single total order across all `SeqCst` operations (the default). |
