## `EntityTable` {#ecs-entitytable}

`class ecs::EntityTable` — defined in `engine/ecs/entity_table.h`

```cpp
class EntityTable { ... }
```

Slots with generations: allocates and frees entity ids and remembers where each alive entity is stored.

A freed slot is reused last-in first-out and its generation is incremented, so the old id no longer matches. Generation 0 is never issued: after 2^32 - 1 reuses of one slot the generation wraps to 1 (counted), and an id older than that wrap could match again, which is documented and accepted.

| Field | Value |
|---|---|
| Thread-safety | thread-compatible. `IsAlive`, `Location` (const) and `Stats` are safe to call concurrently with each other; `Allocate`, `Free` and the mutable `Location` are exclusive (the world calls them at sync points or through its command buffer). |
| Ownership | owns its slots. A pointer from `Location` is valid until the next `Allocate`. |
