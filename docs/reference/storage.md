# Storage

_Generated by docgen. Do not edit._

**Headers:** `engine/storage/builtin_components.h`, `engine/storage/component_registry.h`, `engine/storage/entity_ref.h`, `engine/storage/field.h`, `engine/storage/status.h`

The engine's own components, registered for storage (Phase 19 Day 256): the transform and hierarchy of `ecs` and the membership and bounds of `spatial`. Ids below 1000 belong to this file; a game registers its own components from 1000 up.

[`storage::ComponentRegistry`](#storage-componentregistry) (Phase 19 Day 256): how each component type is stored. A component is registered once with a stable numeric id written in code, a unique name, a version and a list of fields ([`storage::Field`](#storage-field-const-char-star-fieldoptions)); the registry encodes and decodes one component value to and from the canonical bytes, finds a registration by id, name or ECS type, and lists the component types a world holds that nobody registered.

The stored identity of an entity, as a field type: [`storage::EntityKey`](#storage-entitykey) (128 bits) and [`storage::EntityRef`](#storage-entityref) (a reference to another entity by key). Day 256 declares the types and their encoding (16 bytes); Day 258 adds key generation, the key index and the resolution of references on load.

Field descriptions (Phase 19 Day 256): [`storage::Field`](#storage-field-const-char-star-fieldoptions) describes one member of a component by pointer to member, and carries the functions that write it to and read it from the canonical encoding (`foundation/bytes/`). A member whose type has no encoding fails to compile: nothing is skipped silently.

Errors of the storage layer, reported as values: [`storage::ErrorCode`](#storage-errorcode) and [`storage::Status`](#storage-status). No storage failure aborts, and no input, however damaged, is a reason to abort.

## `Field(const char*,FieldOptions)` {#storage-field-const-char-star-fieldoptions}

`function storage::Field` — defined in `engine/storage/field.h`

```cpp
template <auto Member>
FieldDesc Field(const char* name, FieldOptions options = FieldOptions());
```

Describes the member `Member` of a component (`Field<&Health::current>("current")`). The member's type decides the kind: integers, floats, `bool`, `Vec2`, `Vec3`, `Vec4`, `Quaternion`, `Mat4`, `Aabb`, enums, `String<HeapAllocator>`, `Array<T, N>` of those and [`storage::EntityRef`](#storage-entityref). Any other type is a compile error.

The member is a template argument, not a run-time value, so the encode and decode functions are plain function pointers with the member baked in.

| Field | Value |
|---|---|
| Parameter `name` | the field's name, a string literal. |
| Parameter `options` | required for an enum field ([`storage::FieldOptions::Enum`](#storage-fieldoptions-enum-i64-i64)), optional bound for a string ([`storage::FieldOptions::Text`](#storage-fieldoptions-text-u64)). |
| Fails | never at run time; a member without a stored form does not compile. |
| Ownership | `name` is borrowed; pass a literal. |
