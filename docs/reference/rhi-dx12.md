## `Dx12CommandList` {#rhi-dx12-dx12commandlist}

`class rhi::dx12::Dx12CommandList` — defined in `engine/rhi/dx12/dx12_command_list.h`

```cpp
class Dx12CommandList final : public CommandList { ... }
```

A [`rhi::CommandList`](rhi.md#rhi-commandlist) recording into one `ID3D12GraphicsCommandList` with its own command allocator.

The device keeps the lists of each frame slot and hands them out again once that slot's frame has finished, so an allocator is reset only after the GPU is done with it. States: buffers are tracked within the list from `COMMON` (D3D12 returns every buffer there after each `ExecuteCommandLists`, and the device executes each list on its own), promoted implicitly on use and transitioned explicitly from the tracked state; textures keep their state between lists, so a list records the state its first barrier on each texture needs, and the device transitions the texture into it before the list runs (a prologue list built at submit from the states it recorded).

| Field | Value |
|---|---|
| Thread-safety | not-thread-safe: one thread records a list; different lists record on different threads at once. |
| Ownership | owned by its device; the application borrows it from `CreateCommandList` until the frame ends. |

## `Dx12Device` {#rhi-dx12-dx12device}

`class rhi::dx12::Dx12Device` — defined in `engine/rhi/dx12/dx12_device.h`

```cpp
class Dx12Device final : public Device { ... }
```

The Direct3D 12 device: one adapter, one `ID3D12Device` at feature level 12_0, and one direct queue for all work.

Created by [`rhi::CreateDevice`](rhi.md#rhi-createdevice-const-devicecreateinfo-amp) with `Backend::Dx12` (or [`rhi::dx12::Dx12Device::Create`](#rhi-dx12-dx12device-create-const-devicecreateinfo-amp)). With validation on, the debug layer's messages go to [`rhi::LogRhi`](rhi.md#rhi-logrhi) through `ID3D12InfoQueue1`'s callback and are counted ([`rhi::dx12::GetDebugMessageCounts`](#rhi-dx12-getdebugmessagecounts)). Every wait on the GPU is bounded: it waits in slices and checks for a removed device between them.

| Field | Value |
|---|---|
| Thread-safety | thread-safe, as [`rhi::Device`](rhi.md#rhi-device) is: resource creation and destruction from any thread; `Submit`, `BeginFrame`, `EndFrame` and `WaitIdle` belong to one submission thread. |
| Ownership | the caller owns the device through a [`rhi::dx12::Dx12DevicePtr`](#rhi-dx12-dx12deviceptr); it owns the factory, the adapter and the queue. |
