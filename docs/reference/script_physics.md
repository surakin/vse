## `CharacterSet` {#script-physics-characterset}

`class script_physics::CharacterSet` — defined in `engine/script_physics/character_set.h`

```cpp
class CharacterSet { ... }
```

The characters of one physics world.

The set belongs to the host, beside the physics world (`PhysicsScriptServices::characters`). While the script phase runs nothing changes it, so every partition reads it at once; the merge changes the wishes (a command of `character.*`), and the fixed step changes the states.

| Field | Value |
|---|---|
| Thread-safety | thread-compatible; the host serializes `Add`, `Remove`, `Prune` and the step (the merge and the physics step run on one thread), and the script phase only calls the const members. |
| Ownership | owns the controllers; the bodies belong to the physics world, which keeps a pointer to the set (its pre-step hook) until the set is destroyed, so the world must outlive the set. |

## `EmitPhysicsEvents(const physics::PhysicsWorld&,script::ScriptRuntime*,const PhysicsEventOptions&)` {#script-physics-emitphysicsevents-const-physics-physicsworld-amp-script-scriptruntime-star-const-physicseventoptions-amp}

`function script_physics::EmitPhysicsEvents` — defined in `engine/script_physics/physics_events.h`

```cpp
PhysicsEventReport EmitPhysicsEvents(const physics::PhysicsWorld& world, script::ScriptRuntime* runtime, const PhysicsEventOptions& options = PhysicsEventOptions());
```

Puts the physics world's events of the last `Update` or `Step` on the runtime's event bus.

An event is built only for an entity that listens (`ScriptRuntime::HasHandler`: an `event.on` handler or a coroutine in `wait_event`): a step that makes 100,000 contact events costs the lookup per receiver for the entities whose scripts do not listen. A native subscriber of the bus (`EventBus::Subscribe`) sees only the events that reach a listening entity. The payload of a contact event (the receiver is `self`): `other` (the entity), `point` and `normal` (the normal points from `self` toward `other`), `depth`, `impulse` (the solver's normal impulse over the pair), `points` (the manifold's size). A trigger event has `other` (the entity that entered or left) and goes to the trigger's entity only.

Call it after the physics step and before the next script tick, from the thread that runs them.

| Field | Value |
|---|---|
| Parameter `world` | the physics world; its event lists are read. |
| Parameter `runtime` | the runtime whose bus receives the events and whose handlers are asked. |
| Parameter `options` | which events and layers. |
| Returns | the counts. |
| Fails | never; an event with no entity (a body made by hand) is skipped. |
| Thread-safety | thread-compatible; not while a script tick runs. |
| Ownership | borrows both for the call; nothing is kept. |
