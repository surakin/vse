The database interface (Phase 19 Day 252): [`database::Database`](#database-database) opens a [`database::Connection`](#database-connection), a connection prepares [`database::Statement`](#database-statement)s and runs transactions. Upper layers never know the backend: SQLite and the in-memory database implement the same interface and pass one conformance suite. SQL is [`database::SqlText`](#database-sqltext) (a literal) and data is bound, never formatted into the text. Errors are [`database::Status`](#database-status) values.

[`database::SqlText`](#database-sqltext): the only type the database interface accepts as SQL, constructible only from a string literal.

[`database::SqliteDatabase`](#database-sqlitedatabase): the SQLite backend of the database interface.

Errors of the database layer, reported as values: [`database::ErrorCode`](#database-errorcode) and [`database::Status`](#database-status). No database failure aborts.

Typed database values: [`database::ValueView`](#database-valueview) (borrowed) and [`database::Value`](#database-value) (owning).

## `SqliteDatabase` {#database-sqlitedatabase}

`class database::SqliteDatabase` — defined in `engine/database/sqlite/sqlite_database.h`

```cpp
class SqliteDatabase final : public Database { ... }
```

The database interface on SQLite. Built from the vendored amalgamation (`third_party/sqlite`), reached only through this interface.

An empty `OpenOptions::location` or `":memory:"` opens a private in-memory database that belongs to the one connection that opened it; any other location is a file, read and written through the file layer (`io::File`) by the engine's VFS. A file opens in write-ahead-log mode by default, so readers do not block the writer; `Delete` and `Truncate` journals stay selectable. The locks and the log's index live in this process: **a database file belongs to one process at a time** (a second process is not excluded). Savepoints, `WITHOUT ROWID`, `ALTER TABLE ADD COLUMN`, named parameters and foreign keys are supported; the write-ahead log and concurrent readers need a file.

| Field | Value |
