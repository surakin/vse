# The phase that owns each test (Phase 5, docs/superpowers/specs/2026-11-05-test-scoping-design.md).
#
# `<pattern>  <phase>`: a source path relative to the repo root (`*` inside one segment; a trailing `/` is a whole
# directory), or `test:<glob>` for a test that is not a Catch2 test case. Phases: 0 foundation, 1 Linux platform,
# 2 jobs, 2.5 docs tooling, 3 RHI, 4 renderer, 5 test scoping, 6 debugging facilities, 7 RHI reset, 8 file handling. The rule is the phase that owns the behavior, not the directory.
#
# Adding a Catch2 test file: add a line here, or the build stops naming the file. Adding another kind of test: add a
# `test:` line and call engine_label_tests() after add_test. Labels are `phase0` ... `phase8`, `phase2_5`.
# `flavors <phase> plain,asan,tsan` lines (below) list the sanitizer flavors each phase has tests in; a new phase needs one.
