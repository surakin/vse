## `Counter` {#demo-counter}

`class demo::Counter` — defined in `ref/headers/counter.h`

```cpp
class Counter { ... }
```

Tracks outstanding work and lets one coroutine wait for it to finish.

Increment before submitting the work, decrement when it completes.

- The count never goes below zero.
- At most one waiter at a time.

| Field | Value |
|---|---|
| Thread-safety | thread-safe. Any thread may call [`demo::Counter::Increment`](#demo-counter-increment-unsigned-long) and [`demo::Counter::Decrement`](#demo-counter-decrement). |
| Ownership | must outlive every pending decrement. |

**Example** — counting two jobs.

```cpp
Counter c;
c.Increment(2);
```

**See also:** [`Shape`](#demo-shape), [`demo::Counter::Counter`](#demo-counter-counter)
