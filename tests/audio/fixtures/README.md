# Ogg Vorbis fixtures (Phase 26 Day 432)

Generated by `make_fixtures.py` (run it from this directory; it needs `oggenc` from vorbis-tools, libvorbis 1.3.7, and an `ffmpeg` built with libvorbis, as on the
Linux machine). The content is made in the script (sines, noise from a fixed seed, clicks): no third-party recordings, no licence beyond this repository's. The
streams are committed so no machine needs the encoders.

| File | What | Used for |
|---|---|---|
| `sine_mono.ogg` | 440 Hz, mono, 44.1 kHz, 1 s, tags `TITLE`, `ARTIST`, `GENRE` | open, tags, length, frequency |
| `noise_mono.ogg` | seeded noise, mono, 44.1 kHz, 0.5 s | a dense spectrum (long blocks) |
| `stereo_mix.ogg` | 330 Hz left, 550 Hz right and a shared 110 Hz, 48 kHz, 1 s | coupled channels |
| `transient_mix.ogg` | a 220 Hz tone with clicks, mono, 44.1 kHz, 1 s | short and long blocks mixed |
| `surround51.ogg` | 5.1, 48 kHz, 0.3 s, a different frequency per channel (FL 220, FR 330, FC 440, LFE 55, BL 660, BR 880 Hz) | the channel mapping |
| `three_channels.ogg` | 3 channels, 48 kHz | refused: no layout |
| `rate_4000.ogg` | mono, 4 kHz | refused: rate below 8 kHz |
| `flac_in_ogg.ogg` | FLAC in an Ogg container | refused: not Vorbis |
